\section{What the capstone composes}
\label{sec:capstone:overview}

The capstone (Section~\ref{sec:capstone:theorem}) spends four proved ingredients around one hole.

\begin{itemize}
\item \lead{The run split} (\code{erase\_run\_ok}, Ch.~\ref{chap:coldstart}): factors one shipping run
into a preparation and a \code{visitExpr} run from the empty state.
\item \lead{The bridge} (\code{erasure\_bridge\_of\_run}, Ch.~\ref{chap:coldstart}): turns that run
into an intermediate \lbox{} term $t_0$ with an $\Erases$ derivation and a $\Lower$ derivation.
\item \lead{The simulation} (\code{erases\_correct}, Ch.~\ref{chap:correctness}): applied once, at
the applied spine, yielding the target evaluation.
\item \lead{The first-order core} (\code{firstorder\_erases\_core}, \code{noBox\_lower\_of\_foSpine},
Ch.~\ref{chap:correctness}): the answer's constructor-spine shape, erasure uniqueness, lowering
box-freedom.
\item \lead{The hole} No ingredient supplies the shipping eraser's own registration behaviour; that
enters as \hl{\code{hbridge}} (Chapter~\ref{chap:trust}).
\end{itemize}

\lead{Lean} Measured axiom footprint: 33 names, identical at every rung (\code{test/ledger.expected})
-- four standard (\code{propext}, \code{sorryAx}, \code{Classical.choice}, \code{Quot.sound}), 29
non-standard (two \code{bv\_decide} certificates, two lean4lean pointer-equality axioms, the rest
reflection axioms). \code{sorryAx} is inherited from the pinned lean4lean checkout.
\lead{Since the snapshot} The 33 names are unchanged; six of them moved into
\code{erases\_correct}, \code{erases\_correct\_lb} and \code{step\_delta} and out of
\code{bridgeEnv\_of\_regInv} (\code{92105c6}, \code{d6e0e3a}).

\section{The reified source table}
\label{sec:capstone:table}

The verification never reads a \code{Lean.Environment} directly: it reads a \emph{table}, a literal
copied out of one by the \code{reify\%} elaborator.

\begin{definition}[The reified source table]\label{def:Witness-SourceTable}
\lean{LeanToLambdaBox.Witness.SourceTable, LeanToLambdaBox.Witness.ReifiedDecl, LeanToLambdaBox.Witness.ReifiedInduct, LeanToLambdaBox.Witness.ReifiedCtor, LeanToLambdaBox.Witness.SourceTable.decl?, LeanToLambdaBox.Witness.SourceTable.ind?, LeanToLambdaBox.Witness.SourceTable.body?} \leanok
\lead{In short} The reified slice of a Lean elaboration environment the verification reads \hl{in the
environment's place}: named declarations plus named inductive types.
\begin{itemize}
\item \code{ReifiedDecl}: level parameters, kernel type, an optional body -- bodyless for axioms,
theorems, quotient primitives, constructors, recursors and \code{casesOn}-like constants, which the
eraser eliminates with rather than opens;
\item \code{ReifiedInduct}: level parameters, type, parameter/index counts, mutual-block names, and
per \code{ReifiedCtor} its name, type, position and parameter/field split;
\item \code{.decl?}, \code{.ind?}, \code{.body?}: the lookup interface -- \code{.body?} is the
$\delta$-column the source evaluation, $\ErasesEnv$, \code{CompilerBodies} and \code{SpecEnv} read.
\end{itemize}
\lead{Why} \textbf{No} relevance-oracle column (relevance is discharged, not tabled) and \textbf{no}
configuration column: the table is built under one fixed configuration, and a rung states its
configuration obligation separately.
\end{definition}

\begin{definition}[The compiler's view of a declaration]\label{def:Witness-compilerInfo}
\lean{LeanToLambdaBox.Witness.compilerInfo?, LeanToLambdaBox.Witness.compilerValue?, LeanToLambdaBox.Witness.fixBlock?, LeanToLambdaBox.Witness.reifiesBody} \leanok
\lead{In short} Four probes mimicking what the \emph{code generator}, not the kernel, reads of a
declaration.
\begin{itemize}
\item \code{compilerInfo? lenv n}: the \code{\_unsafe\_rec} companion of a recursive \code{n}, else
\code{n} itself;
\item \code{compilerValue?}: that constant's value, \code{allowOpaque := true}; \code{none} means the
eraser emits an axiom instead;
\item \code{fixBlock? lenv n}: the mutual block the eraser installs a fix-variable map for at
\code{n}, after \code{\_unsafe\_rec} stripping;
\item \code{reifiesBody}: true exactly at \code{Lean.ConstantInfo.defnInfo}/\code{.opaqueInfo}.
\end{itemize}
\lead{Why} The eraser reads the compiler body of a recursive definition (calls itself directly),
never the kernel body (eliminates with \code{brecOn}).
\end{definition}

\begin{lemma}[The compiler's view is Lean's own]\label{lem:Witness-compilerInfo-eq}
\lean{LeanToLambdaBox.Witness.compilerInfo?_eq} \leanok
\uses{def:Witness-compilerInfo}
For every name \code{n}, Lean's own \code{Compiler.LCNF.getDeclInfo? n} returns \code{compilerInfo?}
of the ambient environment at \code{n}.
\end{lemma}

\begin{proof} \leanok
\uses{def:Witness-compilerInfo}
\lead{Idea} Both sides unfold \code{getDeclInfo?} the same way; \code{rfl}.
\end{proof}

\begin{definition}[Alpha-equivalence of Lean expressions]\label{def:Witness-Expr-AlphaEq}
\lean{LeanToLambdaBox.Witness.Expr.AlphaEq} \leanok
\lead{In short} Structural equality of \code{Lean.Expr} that ignores binder names and binder info,
and \hl{nothing else}.
\begin{itemize}
\item twelve congruence arms, one per \code{Lean.Expr} constructor; the three binder arms
quantify the two binder names and the two binder annotations away;
\item \textbf{no} metadata-blind arm: \code{.mdata d e} and \code{e} stay unrelated, since the source
semantics has no metadata rule.
\end{itemize}
\end{definition}

\begin{remark}
\lead{Caveat} Extensionally this is \code{Lean.Expr.eqv} (opaque), so \textbf{no theorem connects the
two} (Chapter~\ref{chap:trust} carries the gap as a finding).
\end{remark}

\begin{definition}[Pinning a tabled constant and a tabled inductive type]\label{def:Witness-ReifiedDecl-Pinned}
\lean{LeanToLambdaBox.Witness.ReifiedDecl.Pinned, LeanToLambdaBox.Witness.ReifiedInduct.Pinned} \leanok
\uses{def:Witness-SourceTable}
\lead{In short} A tabled entry is \emph{pinned} when the environment \hl{knows it exactly as tabled}.
\begin{itemize}
\item a constant: the tabled level parameters and type;
\item an inductive type: recorded level parameters, type, parameter/index counts and block, listed in
its own mutual block; each tabled constructor at its position, type, index (= position), parameter
count (= the block's) and field count -- the kernel's own indexing invariants restated.
\end{itemize}
\end{definition}

\begin{definition}[The body column, pinned up to alpha]\label{def:Witness-ReifiedDecl-Prepared}
\lean{LeanToLambdaBox.Witness.ReifiedDecl.Prepared} \leanok
\uses{def:Witness-compilerInfo, def:Witness-Expr-AlphaEq, def:Erasure-prepare_erasure}
\lead{In short} A tabled declaration is \emph{prepared} when every successful \code{csimp}-off run of
\code{Erasure.prepare\_erasure} on the code generator's value returns a term \hl{alpha-equivalent} to
the tabled body -- the one clause of table adequacy about monadic runs rather than a lookup.
\end{definition}

\begin{remark}
\lead{Caveat} With equality the clause would be \textbf{uninhabited} wherever \code{inlineMatchers}
fires (\code{Nat.add} included), naming inlined \code{let}s from the name generator. A consumer owes
an alpha-transport, and $\Lower$ is not alpha-closed on its source -- one of three obstructions to
closing \code{hbridge}. Measured: five bodies match only up to binder names, at G7/G8
(\code{Nat.add}, \code{Nat.mul}, \code{Nat.pow}, \code{Nat.pred}, \code{Nat.sub}).
\lead{Since the snapshot} \stLanded{} \code{512e190} adds \code{Erases.alpha} and
\code{SourceTableAdequate.erases\_prepared}: a tabled body and the run's prepared body have the same
images, so this obstruction is closed at the \Erases{} layer, and
Lemma~\ref{lem:Witness-SourceTableAdequate-body-prepared} gains its first consumer.
\end{remark}

\begin{definition}[Table adequacy]\label{def:Witness-SourceTableAdequate}
\lean{LeanToLambdaBox.Witness.SourceTableAdequate, LeanToLambdaBox.Witness.SourceTableAdequate.decls, LeanToLambdaBox.Witness.SourceTableAdequate.inds} \leanok
\uses{def:Witness-ReifiedDecl-Pinned, def:Witness-ReifiedDecl-Prepared, def:Witness-SourceTable}
\lead{In short} A table is \emph{adequate} for an environment when every tabled constant is
\hl{pinned and prepared}, and every tabled inductive type is pinned.
\lead{Why} No Lean term denotes the ambient environment, so adequacy is undecidable: a permanent
named hypothesis (the capstone's \code{htbl}; Chapter~\ref{chap:trust}).
\end{definition}

\begin{lemma}[A tabled body is a prepared compiler body]\label{lem:Witness-SourceTableAdequate-body-prepared}
\lean{LeanToLambdaBox.Witness.SourceTableAdequate.body?_prepared} \leanok
\uses{def:Witness-SourceTableAdequate, def:Witness-SourceTable}
If a table is adequate and its body column answers $b$ at a name, the code generator's value there
has every \code{csimp}-off preparation run alpha-equivalent to $b$.
\end{lemma}

\begin{proof} \leanok
\uses{def:Witness-SourceTableAdequate, def:Witness-ReifiedDecl-Prepared}
\lead{Idea} Case on the lookup: \code{none} contradicts it; \code{some d} exhibits a column member,
so \code{decls} and its prepared clause give the claim.
\end{proof}

\begin{definition}[Reification: the \code{reify\%} elaborator]\label{def:Witness-elabReify}
\lean{LeanToLambdaBox.Witness.elabReify, LeanToLambdaBox.Witness.Reify.table, LeanToLambdaBox.Witness.Reify.visit, LeanToLambdaBox.Witness.Reify.State, LeanToLambdaBox.Witness.reifyConfig} \leanok
\uses{def:Witness-SourceTable, def:Witness-compilerInfo, def:Erasure-prepare_erasure, def:Erasure-ErasureConfig}
\lead{In short} \code{reify\% c1, ..., cn} elaborates to the source table of the named constants'
dependency closure, \hl{read out of the elaboration's own environment}.
\begin{itemize}
\item \code{Reify.visit}: an inductive type is reified with its whole mutual block; a constructor or
recursor is recorded bodyless; any other constant has its compiler value run through
\code{prepare\_erasure} under \code{reifyConfig} and the prepared body recorded, recursing into names
it mentions;
\item \code{reifyConfig}: \code{csimp := false} -- every correctness statement needs it off, since
\code{csimp} swaps in tail-recursive bodies that are not the declaration's own.
\end{itemize}
\lead{Why} Turns a rung's side conditions into kernel computations on a literal, not assumptions
about an opaque artefact.
\end{definition}

\begin{definition}[The external table check]\label{def:Witness-SourceTable-check}
\lean{LeanToLambdaBox.Witness.SourceTable.check, LeanToLambdaBox.Witness.checkDecl, LeanToLambdaBox.Witness.checkInd, LeanToLambdaBox.Witness.TableMismatch, LeanToLambdaBox.Witness.TableNote, LeanToLambdaBox.Witness.Expr.alphaEqB} \leanok
\uses{def:Witness-SourceTableAdequate, def:Witness-Expr-AlphaEq, def:Witness-elabReify}
\lead{In short} \code{SourceTable.check} \hl{re-derives} a table from the live environment: level
parameters, structural type equality, one preparation run of the body (\code{checkDecl}); block data
and each constructor positionally (\code{checkInd}).
\lead{Caveat} Strictly \textbf{less} than adequacy, which quantifies over all preparation runs, not
one; disagreements are one of twelve \code{TableMismatch} cases. \code{lake exe reify --check} does
\textbf{not} decide table adequacy.
\end{definition}

\section{Translation witnesses: discharging \code{hwt}}
\label{sec:capstone:trwitness}

Two routes supply the capstone's translation binder \code{hwt}: the \emph{table route}, free once a
table is adequate, and a \emph{checker route} through lean4lean's executable type checker.

\begin{lemma}[A declared constant translates]\label{lem:Witness-trExprS_const}
\lean{LeanToLambdaBox.Witness.trExprS_const, LeanToLambdaBox.Witness.trExprS_const_nil} \leanok
\uses{def:ErasureSpec, def:lean4lean-grounding}
Under the specification bundle, a constant the environment declares at an accepted safety translates,
at any local context, to the model constant of the same name, with levels translated pointwise and
the arity read at the declaration's own level parameters. Monomorphic instance: a constant with no
level parameters and no level arguments is its own translation.
\end{lemma}

\begin{proof} \leanok
\uses{def:ErasureSpec, asm:ErasureSpec-decl_adequate, def:lean4lean-grounding}
\lead{Idea} \code{decl\_adequate} turns the lookup into a model constant, a universe-count equality
and a type translation; the constant arm of lean4lean's translation relation applies.
\end{proof}

\begin{lemma}[The declared type of a monomorphic constant, in the model]\label{lem:Witness-hasType_const_nil}
\lean{LeanToLambdaBox.Witness.hasType_const_nil} \leanok
\uses{lem:Witness-trExprS_const, def:ErasureSpec, def:lean4lean-grounding}
If a constant with no level parameters has a declared type that is itself a constant, the model types
it at that constant.
\end{lemma}

\begin{proof} \leanok
\uses{def:ErasureSpec, asm:ErasureSpec-decl_adequate, def:lean4lean-grounding}
\lead{Idea} Inverting \code{decl\_adequate}'s translation of the declared type at a constant type
identifies the model type and forces an empty level list.
\end{proof}

\begin{lemma}[A tabled constant is pinned]\label{lem:Witness-tableDeclPin}
\lean{LeanToLambdaBox.Witness.tableDeclPin} \leanok
\uses{def:Witness-SourceTableAdequate, def:TableSafe}
If a table is adequate and its tabled declarations are safe, a successful table lookup yields a
constant the environment knows, at an accepted safety, with the tabled level parameters and type.
\end{lemma}

\begin{proof} \leanok
\uses{def:Witness-ReifiedDecl-Pinned, def:Witness-SourceTableAdequate, def:TableSafe}
\lead{Idea} A successful lookup exhibits a column member; adequacy's pinning half gives the
environment constant, \code{TableSafe} the safety, at the same lookup.
\end{proof}

\begin{lemma}[The rung's subject translates]\label{lem:Witness-trExprS_const_of_table}
\lean{LeanToLambdaBox.Witness.trExprS_const_of_table} \leanok
\uses{def:Witness-SourceTableAdequate, def:Witness-SourceTable, def:TableSafe, def:ErasureSpec, def:lean4lean-grounding}
Under the specification bundle, an adequate and safe table, and the computed side condition that the
table records no level parameters at a name, the source constant of that name translates to the model
constant of the same name, at any local context.
\end{lemma}

\begin{proof} \leanok
\uses{lem:Witness-tableDeclPin, lem:Witness-trExprS_const}
\lead{Idea} Case on the lookup (\code{none} contradicts the side condition); pinning gives the
constant, the monomorphic translation lemma applies. Discharges \code{hwt} at all eight rungs, side
condition \code{by rfl}.
\end{proof}

\begin{lemma}[The tabled subject's type, in the model]\label{lem:Witness-hasType_const_of_table}
\lean{LeanToLambdaBox.Witness.hasType_const_of_table} \leanok
\uses{def:Witness-SourceTableAdequate, def:Witness-SourceTable, def:TableSafe, def:ErasureSpec, def:lean4lean-grounding}
With the same hypotheses, and the further computed condition that the table records the subject's
type as a constant, the model types the subject at that constant.
\end{lemma}

\begin{proof} \leanok
\uses{lem:Witness-tableDeclPin, lem:Witness-hasType_const_nil}
\lead{Idea} As the previous lemma, typing in place of translation. Function-typed subjects fall
outside it (Lemma~\ref{lem:Green-g8_trExprS_spine}).
\end{proof}

\begin{lemma}[The checker route: a successful run reports a translation]\label{lem:Witness-trTyping_of_checkType_run}
\lean{LeanToLambdaBox.Witness.trTyping_of_checkType_run, LeanToLambdaBox.Witness.trTyping_of_checkType_run_closed} \leanok
\uses{def:ErasureSpec, def:lean4lean-grounding}
If lean4lean's executable type checker, run purely at a well-formed environment and local context,
returns a type for a term whose free variables lie in that context, both translate at that context
and the model types the term at the reported type. Closed instance: a closed term the checker accepts
at the empty context translates with its reported type in the model environment.
\end{lemma}

\begin{proof} \leanok
\uses{def:lean4lean-grounding, lem:Lean4Lean-TypeChecker-M-WF-run-prime, def:Lean4Lean-TypeChecker-VContext-ofMLCtx, asm:ErasureSpec-env_connect, asm:lean4lean-trust, asm:lean-reflection-axioms}
\lead{Idea} lean4lean's well-formedness lemma for \code{checkType} gives the translation and typing
at an abstract verified context; checker adequacy supplies the initial state, so a pure \code{ok} run
witnesses both.
\end{proof}

\begin{remark}
\lead{Caveat} The second route to \code{hwt}, for non-constant subjects: trades a translation binder
for a run equation like \code{hrun}, at the cost of a measured footprint that contains \code{sorryAx}
and the reflection axioms. \textbf{No rung uses it} -- all eight subjects are constants.
\end{remark}

\section{The capstone theorem}
\label{sec:capstone:theorem}

\begin{theorem}[The shipping erasure is correct at first-order answers]\label{thm:shipping_erase_correct_firstorder}
\lean{LeanToLambdaBox.shipping_erase_correct_firstorder} \leanok
\uses{def:Witness-SourceTableAdequate, def:TableSafe, def:TableBlocks, def:ConfigPinned, def:CompilerBodies, def:Supported, def:Erases, def:ErasesEnv, def:Lower, def:LowerEnv, def:SEval, def:SEvalFlags, def:WcbvEval, def:eraseFlags, def:NoBox, def:FirstOrderInd, def:LBWfPeregrine, def:NoBodylessRefs, def:SpecEnv, def:ErasureBridge, def:Erasure-erase, def:Erasure-prepare_erasure, def:Erasure-visitExpr, def:ErasureSpec, def:EraserAsks, def:UpstreamAsks, def:lean4lean-grounding, asm:htbl, asm:hsafe, asm:hblk, asm:hcb, asm:hprep, asm:hrun, asm:ErasureBridge-erasesEnv, asm:ErasureBridge-lowerEnv}
\lead{In short} Under fifteen hypotheses, \hl{\code{Erasure.erase} emits the $\Lower$ image of an
erasure of $e$}, well formed for peregrine, whose \emph{first-order} answers the emitted program
reproduces uniquely and box-free.

\begin{center}
\begin{tabular}{lp{0.38\linewidth}lp{0.20\linewidth}}
\toprule
binder & what it says & class & status \\
\midrule
$P$ (\code{ErasureSpec}) & 8 fields: primitives + model connection & bundle & \stAssumed{} \\
$E$ (\code{EraserAsks}) & this repository's 5 obligations on the eraser & bundle & \stAssumed{} \\
$A$ (\code{UpstreamAsks}) & 4 essential upstream obligations & bundle & \stAssumed{} \\
\code{htbl} & the table is adequate for \code{lenv} & env.\ fact & \stAssumed{} \\
\code{hsafe} & every tabled declaration is safe & env.\ fact & \stAssumed{} \\
\code{hblk} & every fix-installed block is tabled, $\lambda$-headed, non-erasable & env.\ fact & \stAssumed{} \\
\code{hcfg} & the configuration is the pinned one & decidable & \stChecked{} (all 8 rungs) \\
\code{hcb} & every tabled compiler body is kernel-typeable at its type & env.\ fact & \stChecked{} (G1); \stAssumed{} else \\
\code{hwt} & $pe$ translates into the model & table route & \stChecked{} (all 8) \\
\code{hsup} & $pe$ lies in the supported fragment for the table & decidable & \stChecked{} (all 8) \\
\code{hprep} & preparing $e$ from empty state returns $pe$, empty state & run fact & \stAssumed{} \\
\code{hrun} & \code{Erasure.erase e cfg} returns $(\Gamma, t)$, an inlining list & run fact & \stAssumed{} \\
\code{hnb} & every constant $(\Gamma,t)$ reaches has a body & decidable & \stChecked{} (all 8) \\
\code{hwf} & $(\Gamma,t)$ satisfies \code{LBWfPeregrine} & decidable & \stChecked{} (all 8) \\
\code{hbridge} & \code{visitExpr}'s end state yields $\Gamma_{spec}$ with $\code{SpecEnv}$, such that
every $(\Erases, \Lower)$ pair from $pe$ to $t$ satisfies \code{ErasureBridge} & hole & \stOpen{} \\
\bottomrule
\end{tabular}
\end{center}

\lead{Then} there are $\Gamma_{spec}$ and $t_0$ such that:
\begin{enumerate}
\item the preparation ran as assumed (\code{hprep} verbatim);
\item $pe$ erases to $t_0$;
\item $\Gamma_{spec}$ erases the source environment along everything $t_0$ reaches;
\item the lowering takes $t_0$ to $t$, and $\Gamma_{spec}$ to $\Gamma$;
\item $(\Gamma,t)$ satisfies \code{LBWfPeregrine} (\code{hwf} verbatim);
\item \textbf{the observable}: for equal-length lists of source and \lbox{} arguments, each carrying
an erasure/lowering/environment clause of its partner, if the applied spine translates and the source
evaluation of $e$ at the arguments yields a value $v$ that translates and types at a spine of a
first-order inductive $I$, then $v$ has a \textbf{unique} erasure $tv_0$, its lowering $tv$ is
\textbf{box-free}, and the emitted program evaluates $t$ applied to the arguments to $tv$ under
\lbox{}'s call-by-value semantics.
\end{enumerate}

\lead{Lean} Both evaluations are fixed at flag sets (source: \code{fullFlags}; target:
\code{eraseFlags}); local contexts and level scopes stay empty throughout; the argument-indexed
premise uses \code{getElem!} on both lists.

\lead{At the snapshot} \stVacuous{} At five of the eight instances the binder set cannot be
inhabited: \code{hbridge}'s \ErasesEnv{} field demands an erasure of every reached tabled body at
the empty level scope, which no polymorphic body has. G2, G3, G4, G7 and G8 reach 1, 1, 2, 15 and 15
such bodies; G1, G5 and G6 reach none.
\lead{Caveat} Conjunct (1) is the binder \code{hprep} and conjunct (5) the binder \code{hwf},
re-exported unchanged; at every rung the well-formedness, box-freedom and evaluation conjuncts follow
from the literal data alone, and conjuncts (2)--(4) are what the erasure derives.

\lead{Status} \stProved{}; \stInherited{} through lean4lean; conditional on \stAssumed{} $P$
(\code{ErasureSpec}), $E$ (\code{EraserAsks}), $A$ (\code{UpstreamAsks}), \code{ErasureBridge}.
\end{theorem}

\begin{proof} \leanok
\uses{thm:erase_run_ok, thm:erasure_bridge_of_run, thm:prepare_sound, thm:erases_correct, thm:firstorder_erases_core, lem:noBox_lower_of_foSpine, lem:Erases-mkApps, lem:Lower-target_fix, lem:ErasesEnv-mkApps, asm:lean4lean-trust, asm:lean-reflection-axioms}
\lead{Idea} Compose the run split, the bridge, the simulation and the first-order core along the
applied spine.
\begin{enumerate}
\item Split the run (\code{hprep} against \code{erase\_run\_ok}), fixing $pe$.
\item Apply \code{hbridge} for $\Gamma_{spec}$, then the bridge theorem for $t_0$, its erasure and
lowering.
\item Lift the per-argument premise to erasures; carry the source evaluation from $e$ to $pe$.
\item Assemble spine facts for $\Erases$, $\Lower$, $\ErasesEnv$; apply \code{erases\_correct} once.
\item The first-order core gives the constructor-spine shape, erasure uniqueness and box-freedom.
\end{enumerate}
\end{proof}

\begin{remark}
\lead{Caveat} Conjuncts (1), (5) are literally \code{hprep}, \code{hwf}: carried, not derived.
\code{hnb} is used nowhere -- the one genuinely unused binder. \code{hblk} is forwarded to the bridge
theorem, but \code{TableBlocks} itself is consumed by no theorem in the closure: its only consumer is
a lemma that is itself consumed by nothing.
\lead{Deviation} Not concluded at the snapshot: MetaRocq's \code{expanded\_eprogram}. The eraser
emits bare fixpoint bodies (F-ETA), so the theorem concludes the weaker \code{LBWfPeregrine}.
\code{NoBodylessRefs} is this repository's counterpart of MetaRocq's \code{axiom\_free}.
\lead{Since the snapshot} \stFixed{} \code{42989c5} eta-wraps every registered body and
\code{2ace82d} folds expandedness into \code{LBWfPeregrine}; \stPlanned{} the rung environments are
not yet regenerated, so the strengthened clause is still \code{false} at G6, G7 and G8.
\lead{Caveat} \code{hbridge} is inhabited \textbf{nowhere}: \code{bridgeEnv\_of\_regInv}
(Chapter~\ref{chap:coldstart}) would derive it from a registration invariant no theorem establishes
for the shipping eraser.
\end{remark}

\section{The ladder's data}
\label{sec:capstone:data}

\begin{definition}[The eight rung subjects]\label{def:spikeZero}
\lean{spikeZero, spikeLit, spikeLet, spikeProj, spikeCase, spikeRec, spikeFix, arithClosed, benchArith} \leanok
\lead{In short} The ladder's subjects, in order.
\begin{itemize}
\item \code{spikeZero} = \code{Nat.zero}; \code{spikeLit} = \code{Nat.succ 3};
\item \code{spikeLet} = \code{let x := 2; Nat.succ x}; \code{spikeProj} = \code{(Prod.mk 1 2).1};
\item \code{spikeCase} = \code{Nat.casesOn} at \code{Nat.succ (Nat.succ Nat.zero)}, spelled with
\code{casesOn} (not \code{match}) so the iota redex sits in the subject, with a \emph{thunked} nullary
branch -- the shape Lean's match compiler gives a nullary alternative;
\item \code{spikeRec}: the analogous recursive definition; \code{spikeFix} = \code{spikeRec} applied
to \code{Nat.succ (Nat.succ Nat.zero)};
\item \code{arithClosed} = \code{benchArith 0}; \code{benchArith n} = the tracked benchmark
$2^{((n \cdot 3) - n) + 3}$.
\end{itemize}
\end{definition}

\begin{remark}
\code{spikeZero}--\code{arithClosed} are declared at the \textbf{root} namespace, matching the
committed emitted environments. \code{benchArith} lives in the frozen benchmark source
\code{VerifyBench/Src/Arith.lean}, byte-identical against the sibling \code{benchmarks} repository.
\end{remark}

\begin{definition}[The pinned configuration]\label{def:Green-spikeConfig}
\lean{LeanToLambdaBox.Green.spikeConfig} \leanok
\uses{def:Erasure-ErasureConfig, def:ConfigPinned}
\lead{In short} Every rung is erased at \hl{one} configuration: \code{extern := .preferLogical},
\code{nat := .peano}, \code{csimp := false}, the rest at their defaults -- \textbf{not} the default
\code{\#erase} configuration, which this differs from on three of its five fields, with
\code{csimp} and constructor-argument pruning off (unlike the default).
\end{definition}

\begin{lemma}[The rungs' configuration is the pinned one]\label{lem:Green-spike_configPinned}
\lean{LeanToLambdaBox.Green.spike_configPinned} \leanok
\uses{def:Green-spikeConfig, def:ConfigPinned}
The rung configuration satisfies \code{ConfigPinned}.
\end{lemma}

\begin{proof} \leanok
\uses{def:Green-spikeConfig, def:ConfigPinned}
\lead{Idea} Five field equations, each \code{rfl} on the literal configuration. Discharges the
capstone's \code{hcfg} at all eight rungs.
\end{proof}

\begin{definition}[The literal answers: peano numerals in \lbox{}]\label{def:Green-peanoLB}
\lean{LeanToLambdaBox.Green.peanoLB, LeanToLambdaBox.Green.litLB, LeanToLambdaBox.Green.natIid, LeanToLambdaBox.Green.ofNatIid, LeanToLambdaBox.Green.ofNatKn, LeanToLambdaBox.Green.instOfNatNatKn} \leanok
\uses{def:LBTerm, def:InductiveId, def:Kername}
\lead{In short} \code{peanoLB n}: the zero constructor node under $n$ successor nodes, each carrying
an \hl{empty} argument list -- what the eraser emits for a \code{Nat} literal under
\code{nat := .peano}. \code{litLB n}: the emitted image of a \emph{source} literal, \code{OfNat.ofNat}
applied to the erased carrier type ($\Box$), the numeral, and the instance.
\end{definition}

\begin{remark}
The \emph{applied} constructor convention -- every emitted constructor node has an empty argument
list (measured 982 of 982 across the five benchmark programs, F-ETA2), unlike CertiCoq's block form
-- and \code{litLB}'s $\Box$ where the carrier type was (the box rule of [L, S Sec.~7.3]) are both
visible here.
\end{remark}

\begin{definition}[The per-rung committed data]\label{def:Green-g1Table}
\lean{LeanToLambdaBox.Green.g1Table, LeanToLambdaBox.Green.eG1, LeanToLambdaBox.Green.g1Env, LeanToLambdaBox.Green.g1Term, LeanToLambdaBox.Green.g1Answer, LeanToLambdaBox.Green.g2Table, LeanToLambdaBox.Green.g3Table, LeanToLambdaBox.Green.g4Table, LeanToLambdaBox.Green.g5Table, LeanToLambdaBox.Green.g6Table, LeanToLambdaBox.Green.g7Table, LeanToLambdaBox.Green.g8Table, LeanToLambdaBox.Green.g8Arg, LeanToLambdaBox.Green.arithTower, LeanToLambdaBox.Green.g7Tag, LeanToLambdaBox.Green.g8Tag} \leanok
\uses{def:Witness-elabReify, def:Green-peanoLB, def:GlobalDeclarations, def:LBTerm}
\lead{In short} Each rung commits \hl{four literals and one answer}.
\begin{itemize}
\item \code{g<i>Table} = \code{reify\% <subject>}, the reified environment slice;
\item \code{eG<i>}: the source term \code{\#erase <subject>} elaborates;
\item \code{g<i>Env}, \code{g<i>Term}: the emitted program, transcribed by hand from the committed
\code{.ast} under \code{VerifyBench/ast/Spikes/};
\item \code{g<i>Answer}: the literal peano numeral the rung claims.
\end{itemize}
\lead{Lean} G7 and G8 share \code{arithTower} (39 declarations, \code{benchArith}'s dependency
closure). \code{g8Env} \textbf{is} \code{arithTower g8Tag}; \code{g7Env} conses
\code{arithClosed}'s own body onto the same tower, at a different macro-scope tag.
\end{definition}

\begin{remark}
\lead{Caveat} This is \hl{data, not a claim}.
\begin{itemize}
\item its correspondence to a real run is the binder \code{hrun}, checked only by
\code{lake exe green-check}'s byte-diff, since no Lean term can inhabit \code{IO.RealWorld};
\item the emitted \code{Nat.add} and \code{Nat.mul} fixpoints recurse on their \textbf{second}
argument, the Lean-versus-Rocq asymmetry the benchmark repository also documents.
\end{itemize}
\end{remark}

\section{G5: the source evaluation, derived}
\label{sec:capstone:g5}

At every other rung the source evaluation is a binder. G5 derives it, at the cost of two model-side
bundles.

\begin{definition}[G5's source-side vocabulary]\label{def:Green-peanoSrc}
\lean{LeanToLambdaBox.Green.peanoSrc, LeanToLambdaBox.Green.g5Motive, LeanToLambdaBox.Green.g5Minor0, LeanToLambdaBox.Green.g5Minor1, LeanToLambdaBox.Green.g5Body} \leanok
\uses{def:Green-g1Table}
A peano numeral in \emph{source constructor form}; G5's motive; its thunked nullary minor (the
identity thunk at \code{Unit.unit}); its successor minor (the identity function); and \code{g5Body},
the eliminator spine \code{Nat.casesOn} at the motive, the value 2 and the two minors -- the body
G5's table records for the subject.
\end{definition}

\begin{remark}
\lead{Why} The thunked nullary branch is not a fixture artefact: it is the shape Lean's match
compiler gives a nullary alternative, and it is exactly what makes the iota rule's per-branch
obligation visible.
\end{remark}

\begin{lemma}[G5's tabled bodies, computed]\label{lem:Green-g5_body_eq}
\lean{LeanToLambdaBox.Green.g5_body_eq, LeanToLambdaBox.Green.g5_unit_body_eq} \leanok
\uses{def:Green-peanoSrc, def:Green-g1Table}
G5's table records the eliminator spine as the subject's body, and \code{PUnit.unit} as
\code{Unit.unit}'s.
\end{lemma}

\begin{proof} \leanok
\uses{def:Green-peanoSrc, def:Green-g1Table}
\lead{Idea} \code{rfl} on the reified literal.
\end{proof}

\begin{definition}[What the model must declare about \code{Nat}]\label{def:Green-SpikeNatFacts}
\lean{LeanToLambdaBox.Green.SpikeNatFacts, LeanToLambdaBox.Green.SpikeNatFacts.natInd, LeanToLambdaBox.Green.SpikeNatFacts.natZero, LeanToLambdaBox.Green.SpikeNatFacts.natSucc, LeanToLambdaBox.Green.SpikeNatFacts.natCases, LeanToLambdaBox.Green.SpikeNatFacts.natCasesOrigin, LeanToLambdaBox.Green.SpikeNatFacts.natInf} \leanok
\uses{def:IndInfo, def:CtorOf, def:CasesOnShape, def:ConstOrigin, def:InformativeInd}
\lead{In short} Six model-side facts about \code{Nat}, \hl{read in the model}.
\begin{itemize}
\item \code{Nat} has no parameters and two constructors, of zero and one field;
\item \code{Nat.zero}, \code{Nat.succ} are those constructors at indices 0, 1;
\item \code{Nat.casesOn} has one argument before the major premise and two minors, and is a
\emph{plain} constant;
\item \code{Nat} eliminates into data: its result sort is never \code{Prop} (informativeness).
\end{itemize}
\lead{Why} A hypothesis bundle: the transport from the reified table to these facts is upstream
ask 3.
\end{definition}

\begin{lemma}[The \code{Nat} bundle is satisfiable]\label{lem:Green-spikeNatFacts_natEnv}
\lean{LeanToLambdaBox.Green.spikeNatFacts_natEnv} \leanok
\uses{def:Green-SpikeNatFacts, prop:NatWitness-seval_iota_fires}
The \code{Nat} bundle holds at the source-evaluation chapter's model fixture.
\end{lemma}

\begin{proof} \leanok
\uses{def:Green-SpikeNatFacts, prop:NatWitness-seval_iota_fires}
\lead{Idea} That fixture's own theorems supply every field directly. Footprint
\code{[propext, Classical.choice, Quot.sound]}: no \code{sorryAx}. The non-vacuity guard for G5's and
G8's model-side bundle.
\end{proof}

\begin{definition}[What the model must declare about \code{PUnit}]\label{def:Green-SpikeUnitFacts}
\lean{LeanToLambdaBox.Green.SpikeUnitFacts, LeanToLambdaBox.Green.SpikeUnitFacts.punitInd, LeanToLambdaBox.Green.SpikeUnitFacts.punitUnit} \leanok
\uses{def:IndInfo, def:CtorOf}
\code{PUnit} is declared with no parameters and one nullary constructor, and \code{PUnit.unit} is
that constructor.
\end{definition}

\begin{remark}
\lead{Caveat} Kept separate from the \code{Nat} bundle because the model fixture declares a single
block; the two halves are satisfiable only at different fixtures. \textbf{This half is inhabited
nowhere}: G5's non-vacuity holds modulo a bundle half whose consistency is not exhibited.
\end{remark}

\begin{lemma}[Source peano numerals are values]\label{lem:Green-peanoSrc_eval}
\lean{LeanToLambdaBox.Green.peanoSrc_eval} \leanok
\uses{def:Green-SpikeNatFacts, def:Green-peanoSrc, def:SEval}
Given the \code{Nat} bundle, every peano numeral in source constructor form evaluates to itself, at
any body column, level scope and flag set.
\end{lemma}

\begin{proof} \leanok
\uses{def:Green-SpikeNatFacts, def:Green-peanoSrc, def:SEval}
\lead{Idea} Induction on the numeral; the constructor-value rule applies at zero and successor.
\end{proof}

\begin{lemma}[Neither the subject nor the thunk's argument is an eliminator]\label{lem:Green-not_casesOn_spikeCase}
\lean{LeanToLambdaBox.Green.not_casesOn_spikeCase, LeanToLambdaBox.Green.not_casesOn_unitUnit} \leanok
\uses{def:CasesOnShape}
No \code{CasesOnShape} holds of \code{spikeCase}, nor of \code{Unit.unit}, at any inductive type,
prefix depth or minor count.
\end{lemma}

\begin{proof} \leanok
\uses{def:CasesOnShape}
\lead{Idea} \code{CasesOnShape}'s name condition is decidable and refuted by \code{decide}. These are
the side conditions making a delta step the only move at those two heads.
\end{proof}

\begin{proposition}[G5's source evaluation, derived]\label{prop:Green-g5_seval}
\lean{LeanToLambdaBox.Green.g5_seval} \leanok
\uses{def:Green-SpikeNatFacts, def:Green-SpikeUnitFacts, def:Green-peanoSrc, def:Green-g1Table, def:SEval, def:StepDefeq, def:SEvalFlags}
Given the \code{Nat} and \code{PUnit} bundles and three definitional-step facts (the subject is
definitionally its tabled body; \code{Unit.unit} is definitionally \code{PUnit.unit}; the eliminator
spine is definitionally the selected minor applied to the constructor's field), the source evaluation
takes G5's subject to the source numeral 1, at the full flag set.
\end{proposition}

\begin{proof} \leanok
\uses{lem:Green-g5_body_eq, lem:Green-peanoSrc_eval, lem:Green-not_casesOn_spikeCase, def:Green-SpikeNatFacts, def:Green-SpikeUnitFacts, def:SEval}
\lead{Idea} A delta step exposes the eliminator spine; the iota rule fires at \code{Nat.casesOn}
(block data from the \code{Nat} bundle), and the selected minor beta-reduces to numeral 1; the
unselected nullary minor needs a beta step whose argument needs a delta step at \code{Unit.unit}
(\code{PUnit} bundle).
\end{proof}

\begin{remark}
\lead{Caveat} The only place the capstone's source-evaluation premise is a term, not a binder --
the ladder's non-vacuity high-water mark. No witness is attempted at Arith: \code{benchArith 0} runs
45 recursive calls, each owing a per-branch obligation for every unselected minor -- a recorded
fallback, not an oversight.
\end{remark}

\section{The tooling that re-measures}
\label{sec:capstone:tooling}

Nothing here is a graph node: all of it re-derives, outside the kernel, what the rungs assume.

\begin{itemize}
\item \code{lake exe green-check}: byte-diffs a rung's regenerated \code{.ast} against the committed
one and runs the certified evaluator against the answer -- the external check of \code{hrun}.
\item \code{lake exe reify --check/--blocks/--prepared}: re-derives a committed table from the live
environment, re-checks \code{TableBlocks}, checks \code{hprep}; CI runs all three, plus a
deliberately stale table that must be rejected.
\item \code{scripts/ledger.sh}: diffs 40 \code{\#print axioms} against \code{test/ledger.expected};
\code{lean4lean-sorries.sh} pins the trust boundary at sixteen \code{sorry} sites; \code{frozen.sh}
holds the benchmark sources byte-identical against the sibling repository.
\item \code{lake exe coverage}/\code{hygiene}: measures drift and enforces documentation policy,
with a budget of 240 declarations outside the import closure of \code{Green.lean} and
\code{Capstone.lean}. \lead{Since the snapshot} 242 after the vacuity regression file
(\code{cf2cb08}), 245 at \code{184155d}.
\end{itemize}

\section{Deviations from the paper, and caveats}
\label{sec:capstone:caveats}

\begin{itemize}
\item \lead{Deviation} \lbox{}'s own weak call-by-value evaluation replaces MetaRocq's; the extra
$\Lower$ relation splits the environment side; source evaluation reads a compiler-body table, not
kernel $\delta$.
\item \lead{Deviation} Constructors are emitted applied, never as blocks (F-ETA2); no fixpoint
eta-expansion, so output meets \code{LBWfPeregrine} but not the stronger expanded-fixpoint condition
(F-ETA).
\item \lead{Caveat} Eight literal answers rule out a proof by $\Box$ or a stuck term, but not one
by unsatisfiable hypotheses: \stVacuous{} \lead{At the snapshot} five rungs had exactly that
(Section~\ref{sec:capstone:rungs}). Every computable hypothesis is still checked at every rung it
applies to.
\item \lead{Caveat} \code{lenv} and \code{env} stay universally quantified at every rung; \code{hrun}
is an equation about an opaque world token no Lean term inhabits; \code{hbridge} is inhabited nowhere.
\item \lead{Caveat} \code{hcb} is a binder at seven rungs, \code{hev} at seven; G5's \code{PUnit}
bundle half is satisfied by no fixture.
\item \lead{Caveat} \stRefuted{} Two \code{EraserAsks} fields are false of the shipping code in
general --- the kernel inductive-head field (F-DEPTH), block-key distinctness (F-UNSAFEREC) ---
though true on every measured input; both bound what ``verified'' means here.
\lead{Since the snapshot} \stFixed{}/\stLanded{} The first field's counterexamples are gone
(\code{33ba53e}) and its docstring names the residue; the second is deleted and derived from a
successful run instead (\code{db1c2b6}, \code{184155d}).
\end{itemize}
