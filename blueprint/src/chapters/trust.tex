\section{con-leche's trust base}\label{sec:trust-conleche}

\begin{itemize}
\item \lead{Pin} the \code{con-leche} package of Section~\ref{sec:intro-pins}, never edited and never
  re-pinned; \code{proof/spec.pin} holds the digest of every con-leche definition the statements
  reach.
\item \lead{Footprint} \leandecl{ConLeche.model_exists} and \leandecl{ConLeche.no_False_declaration} depend
  on the standard axioms only (\leanfile{LeanToLambdaBox/ConLeche.lean} pins both).
\item \lead{The model hypothesis} \hl{\code{Sound} quantifies over a \code{SetTheory} model inside its
  conclusion}, as \leandecl{ConLeche.model_exists} does: the instance is a hypothesis, never an
  axiom. Inside Lean no instance exists without con-leche's \code{bridge/} package, which proves
  one from an hypothesis on inaccessible cardinals. No module of this repository imports that
  package or Mathlib, so the statements hold vacuously where no model exists, and no theorem of
  this repository shows that one does.
\item \lead{No sorry} no declaration of the audited environment depends on \code{sorryAx}.
\item \lead{Module system} con-leche is built with Lean's module system; the proof reads only
  what its modules expose.
\item \lead{Checker modes} the proof applies con-leche's entry points at the verified mode only.
\end{itemize}

\section{Programs with an inductive type}\label{sec:trust-gap}

\begin{itemize}
\item \lead{The gap} the kernel cannot run con-leche's fold on an inductive block: the installer
  hashes names with an opaque hash, and $\iota$ and level comparison use well-founded functions.
  The test programs check the fold equation of \code{hacc}, and any certificate that needs
  $\iota$, by compiled evaluation (\code{\#eval}), which trusts Lean's compiler.
\item \lead{What the kernel checks} every other hypothesis; inductive-free programs are
  kernel-checked end to end.
\end{itemize}

\section{The shipping code}\label{sec:trust-shipping}

monad. \code{\#erase} runs it with the pure backend on programs in the fragment, and with the
\code{CoreM} backend, which asks the elaborator for types, on the others. The census of its
partial, opaque, unsafe and monadic declarations follows.
