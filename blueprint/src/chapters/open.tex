\section{Results}\label{sec:open-results}

\begin{itemize}
\item \lead{First-order corollary} \stOpen{} for a value of a non-\code{Prop} inductive with
  first-order arguments, \code{vb} is its structural erasure, with an instance on NV-1, as
  MetaRocq's \code{erase\_correct\_strong}. The final theorem gives only an erasure of \code{v};
  \code{IsErasable.ctor\_not} excludes $\Box$ for data constructors.
\item \lead{Well-formed output} \stOpen{} fresh kernames, declaration order and well-formed terms
  of the emitted program, which composing with Peregrine's verified pipeline needs, as a conjunct
  or a separate theorem; \code{peregrine validate} checks them at run time (C11).
\item \lead{Non-vacuity} \stOpen{} an instance with a projection and a Peano literal; a check of
  NV-P's declarations against the kernel's.
\end{itemize}
