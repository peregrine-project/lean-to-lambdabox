\section*{At a glance}
\begin{itemize}
\item \lead{Goal} Prove \code{erasePure\_erases}: the output of the shipping traversal \code{erasePure} on the closure \code{collectDeps} returns is an erasure of the marking of the input. Prove also what the fragment test and the entry point preserve.

\section{The steps of the traversal}\label{sec:core-steps}

\code{erasePure\_erases} is an induction on the fuel of \code{visitExpr}; each node below proves the case of one family of terms against the invariant \code{ExprSpec}. The marking opens a binder with any fresh variable and the traversal with the next variable of its counter, so each step relates a marking under locals to a run on the renamed term (\code{RenOK}).

\section{The marking exists}\label{sec:core-exists}

The traversal returns a result only along a derivation of \code{MarkOf}. The proof reads the successful run of \code{visitExpr} case by case and builds the marking; it uses that no run lowers the counter of fresh variables or loses a registered mask.

\section*{Caveats}
\begin{itemize}
\item \code{collectDeps\_spec} takes the hypothesis that every recursor's type names its block's members.
\item \code{register\_inductive\_ok} takes the block facts the run does not check as premises.
\item The existence of a marking uses \code{ClosedDecls}, acceptance and the absence of mark keys; it does not use \code{NoPreDefs}.
\item The \code{propositional} flag is the syntactic test; a sort \code{max 0 0} is outside the fragment (DV-14).
\end{itemize}
