\section{The entry point: what a run of the shipping eraser is}
\label{sec:coldstart:entry}

Every invariant in this chapter is engineered to be free at the empty state, because
Theorem~\ref{thm:erase_run_ok} shows that is where a real run starts.

\begin{theorem}[The cold-start entry point]
\label{thm:erase_run_ok}
\lean{LeanToLambdaBox.erase_run_ok}
\leanok
\uses{def:Erasure-erase, def:Erasure-EraseM, def:Erasure-prepare_erasure, def:Erasure-visitExpr}
\lead{In short} A successful run of the shipping entry point \hl{is} a preparation run followed by a
term walk, both from the empty state.
\begin{itemize}
\item \lead{Given} \code{Erasure.erase e cfg} succeeds at world $w$, returning program $p$ and
inlining list \code{inls};
\item \lead{Then} there are \code{pe}, $t$, states \code{sp}, \code{sf} with
\code{prepare\_erasure e \{\} \{config := cfg\}} at \code{(pe, sp)},
\code{visitExpr pe sp \{config := cfg\}} at \code{(t, sf)}, $p = \code{.untyped sf.gdecls (some t)}$,
$\code{inls} = \code{sf.inlinings}$;
\item no condition on $e$, the configuration, or the state.
\end{itemize}
\lead{Status} \stProved{}.
\end{theorem}
\begin{proof}
\leanok
\uses{lem:Erasure-run_bind_ok, lem:Erasure-run_pure, def:Erasure-EraseM}
\lead{Idea} Unfold \code{Erasure.erase} and split its binds; \code{run\_eq} rewrites
\code{Erasure.run x cfg} to \code{x \{\} \{config := cfg\}} by \code{rfl}, exposing the empty state and
entry reader, and a further bind inversion splits preparation from the walk.
\end{proof}
\begin{theorem}[The preparation pass, with the \code{csimp} gate off]
\label{thm:run_prepare_erasure_ok}
\lean{LeanToLambdaBox.run_prepare_erasure_ok}
\leanok
\uses{def:Erasure-prepare_erasure, def:ConfigPinned, def:Erasure-EraseM}
\lead{In short} With \code{csimp} off, a \code{prepare\_erasure} run is exactly its four
\code{CoreM}-lifted transforms, in order, and touches no state.
\begin{itemize}
\item \lead{Given} the reader's configuration has $\code{csimp} = \code{false}$ (the first conjunct of
\code{ConfigPinned});
\item \lead{Then} a successful run leaves the erasure state untouched and is exactly
\code{Erasure.replaceUnsafeRecNames}, \code{Lean.Compiler.LCNF.macroInline},
\code{Lean.Compiler.LCNF.inlineMatchers}, then \code{macroInline} again, each sub-run handed back
individually.
\end{itemize}
\lead{Status} \stProved{}.
\end{theorem}
\begin{proof}
\leanok
\uses{lem:Erasure-run_bind_ok, lem:Erasure-run_liftCoreM_ok, lem:Erasure-run_pure}
\lead{Idea} Unfold \code{prepare\_erasure} and step every bind. All four transforms are \code{CoreM}
actions reached through \code{liftM}, so the run algebra's state-transparency lemma applies to each; the
one non-lift branch, a \code{Lean.Core.transform} guarded by \code{@[csimp]}, is dead under the
hypothesis.
\end{proof}
\begin{lemma}[The preparation leaves the state alone]
\label{lem:run_prepare_erasure_state}
\lean{LeanToLambdaBox.run_prepare_erasure_state}
\leanok
\uses{def:Erasure-prepare_erasure, def:ConfigPinned}
\lead{In short} At $\code{csimp} = \code{false}$, a successful \code{prepare\_erasure} run ends in the
state it started in.
\end{lemma}
\begin{proof}
\leanok
\uses{thm:run_prepare_erasure_ok}
\lead{Idea} The first projection of Theorem~\ref{thm:run_prepare_erasure_ok}.
\end{proof}
\begin{theorem}[The preparation preserves the source evaluation]
\label{thm:prepare_sound}
\lean{LeanToLambdaBox.prepare_sound}
\leanok
\uses{def:Erasure-prepare_erasure, def:EraserAsks, def:SEval, def:SEvalFlags, def:ConfigPinned, def:mkApps}
\lead{In short} \hl{Preparation preserves \SEval{}}: if it takes $e$ to \code{pe}, \SEval{} on a spine
at $e$ still holds at the same spine on \code{pe}.
\begin{itemize}
\item \lead{Given} \code{EraserAsks} and $\code{csimp} = \code{false}$, and
\code{prepare\_erasure} takes $e$ to \code{pe};
\item \lead{Then} for every spine \code{args}, body table, level scope, flag point and value $v$: if
$\SEval{}\ (\mkApps\ e\ \code{args})\ v$, then $\SEval{}\ (\mkApps\ \code{pe}\ \code{args})\ v$.
\end{itemize}
\lead{Status} \stProved{} conditional on \stAssumed{} \code{EraserAsks}.
\end{theorem}
\begin{proof}
\leanok
\uses{thm:run_prepare_erasure_ok, asm:EraserAsks-passes_sound}
\lead{Idea} Theorem~\ref{thm:run_prepare_erasure_ok} exposes the four sub-runs; each distinct pass is a
member of \code{preparePasses}, and \code{EraserAsks.passes\_sound} chains the four evaluations. The
spine stays quantified since a whole-tree transform does not commute with \mkApps{}.
\end{proof}

\section{What every run produces: one induction, eighteen motives}
\label{sec:coldstart:induction}

The induction abstracts what a state predicate must be closed under, so one proof spends the eighteen
step cases once and serves every consumer.

\begin{definition}[Closure of a state predicate under the eraser's steps]
\label{def:RunClosed}
\lean{LeanToLambdaBox.RunClosed}
\leanok
\uses{def:Erasure-EraseM, def:Erasure-register_inductive, def:Erasure-prepare_erasure, def:Erasure-nonrecConstState, def:NoFix, def:LBClosed}
\lead{In short} A six-field \code{Prop} structure, one field per place the erasure family touches the
state.
\begin{itemize}
\item \code{inl}: the \code{@[inline]} bookkeeping cons;
\item \code{ax}, \code{reg}: the two registration primitives, stated at a run (covering
\code{addAxiom}'s panic fall-through and \code{register\_inductive}'s cold branch);
\item \code{prep}: the preprocessing pass;
\item \code{nrc}: \code{visitMutual}'s non-recursive exit, may assume the stored term fix-free, closed,
applied;
\item \code{rc}: the recursive exit, may assume only closedness and applied form (a fixpoint projection
is never fix-free).
\end{itemize}
\end{definition}
\begin{definition}[The per-call conclusions]
\label{def:ShapeCW}
\lean{LeanToLambdaBox.ShapeCW, LeanToLambdaBox.ShapeC}
\leanok
\uses{def:NoFix, def:LBClosed, def:Erasure-EraseM}
\lead{In short} Two readings of ``the state predicate survives and the output is well shaped''.
\begin{itemize}
\item $\code{ShapeC}\ Q\ s\ s'\ t$: $Q$ at entry gives $Q$ at exit and $t$ fix-free, closed at level
$0$, applied (spine) form;
\item $\code{ShapeCW}\ \code{Cfg}\ P\ \code{ctx}\ s\ w\ s'\ w'\ t$: its world-indexed twin, at entry
state-and-world plus \code{Cfg}.
\end{itemize}
\end{definition}
\begin{remark}
\lead{Deviation} Applied form is a \emph{conclusion} here: the eraser's one constructor site is nullary
by design. MetaCoq instead ships a verified block/applied transformation.
\end{remark}
\begin{definition}[Closure of a world-indexed state predicate]
\label{def:RunClosedW}
\lean{LeanToLambdaBox.RunClosedW}
\leanok
\uses{def:RunClosed, def:Erasure-isErasable, def:Erasure-register_inductive, def:Erasure-prepare_erasure, def:Erasure-EraseM}
\lead{In short} Sixteen fields, parameterised by a condition \code{Cfg} on the configuration and a
predicate $P$ of the state \emph{and} world.
\begin{itemize}
\item ten, one per ambient primitive called: \code{oracle}, \code{inferType}, \code{constInfo},
\code{getEnv}, \code{logInfo}, \code{isInstance}, \code{fresh}, \code{declInfo}, \code{ctorArity},
\code{casesInfo} --- respectively \code{Erasure.isErasable}, \code{Lean.Meta.inferType},
\code{Lean.getConstInfo}, \code{Lean.getEnv}, \code{Lean.logInfo}, \code{Lean.Meta.isInstance},
\code{Lean.mkFreshFVarId}, \code{Lean.Compiler.LCNF.getDeclInfo?}, \code{Lean.Compiler.LCNF.getCtorArity?},
\code{Lean.getCasesInfo?};
\item the other six are \code{RunClosed}'s (Definition~\ref{def:RunClosed}), except \code{prep} and
\code{reg} also read \code{Cfg}, and \code{reg} carries the inductive value's provenance: a
\code{getConstInfo} run, or \code{nat} = \code{.machine}.
\end{itemize}
\end{definition}
\begin{remark}
\lead{Why} The world index states a relation between two states (\code{RunConcl}) and a generator
bound; the two \code{Cfg}-reading clauses are forced by \code{prepare\_erasure}'s \code{csimp} branch
and \code{register\_inductive}'s pruning mask.
\end{remark}
\begin{lemma}[A state predicate is a world-blind world-indexed one]
\label{lem:runClosedW_of_runClosed}
\lean{LeanToLambdaBox.runClosedW_of_runClosed}
\leanok
\uses{def:RunClosed, def:RunClosedW}
\lead{In short} If $Q$ is closed under the eraser's steps as a state predicate, then $\lambda s\,\_.\ Q\ s$
is closed under them as a world-indexed one, at any \code{Cfg}.
\end{lemma}
\begin{proof}
\leanok
\uses{def:RunClosed, def:RunClosedW, lem:Erasure-run_liftCoreM_ok}
\lead{Idea} The ten primitive fields are discharged by the run algebra's state-transparency lemmas; the
six \code{RunClosed} fields carry over with \code{Cfg} unread.
\end{proof}
\begin{lemma}[The stored fixpoint block is closed and in applied form]
\label{lem:rec_block_closed}
\lean{LeanToLambdaBox.rec_block_closed, LeanToLambdaBox.rec_block_noBlock}
\leanok
\uses{def:LBClosed, def:NoFix, def:toBvar, def:Erasure-mkLambda}
\lead{In short} A block whose bodies are closures of closed terms yields a fixpoint node whose
projections are closed and applied.
\begin{itemize}
\item \lead{Given} \code{defs} with one entry per member, a fixvar-name list of the same length, and
every body the fold of \code{toBvar} over the reversed, indexed names applied to a closed term;
\item \lead{Then} the $j$-th projection is closed at level $0$ for every $j$; with closedness replaced
by applied form, it is applied form for every $j$.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{lem:lbClosed_fix_of_bodies, def:LBClosed}
\lead{Idea} Closedness unfolds to ``every body closed at the block's length'', and each abstraction
raises the level by one. Applied form has no binder arithmetic and is discharged directly.
\end{proof}
\begin{lemma}[The binder helpers, world-indexed]
\label{lem:run_withLocalDecl_okW}
\lean{LeanToLambdaBox.run_withLocalDecl_okW, LeanToLambdaBox.run_withLocalDef_okW, LeanToLambdaBox.run_lambdaMonocular_okW, LeanToLambdaBox.run_letMonocular_okW, LeanToLambdaBox.run_forallMonocular_okW, LeanToLambdaBox.run_lambdaMonocularOrIntro_okW, LeanToLambdaBox.run_lambdaOrIntroToArity_okW}
\leanok
\uses{def:Erasure-mkLambda, def:Erasure-EraseM}
\lead{In short} Seven decompositions of the eraser's binder-opening helpers, reporting what the
continuation inherits.
\begin{itemize}
\item the continuation's reader keeps the caller's configuration (only local context, fixvar map, level
scope move);
\item $P$ survives to the continuation's entry, the freshness run included;
\item the monocular family carries its \code{panic!} fall-through as an explicit disjunct, discharged
not excluded;
\item the last helper peels exactly \code{arity} binders by structural recursion.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{lem:Erasure-run_panic, lem:Erasure-run_pure, lem:Erasure-run_bind_ok}
\lead{Idea} Unfold each helper and step its binds; a world-indexed induction needs the continuation's
reader (for \code{RunClosedW}'s \code{Cfg}-reading clauses) and its advanced world, which the plain run
algebra drops.
\end{proof}
\begin{remark}
\lead{Caveat} The arity-peeling helper's panic case reports $P$ at the exit rather than equal worlds
--- an asymmetry with its four siblings.
\end{remark}
\begin{lemma}[The two registering exits, world-indexed]
\label{lem:run_nonrec_exit_okW}
\lean{LeanToLambdaBox.run_nonrec_exit_okW, LeanToLambdaBox.run_rec_exit_okW}
\leanok
\uses{def:RunClosedW, def:Erasure-visitMutual, def:Erasure-nonrecConstState}
\lead{In short} Two decompositions of \code{visitMutual}'s registering exits, keeping $P$ alive.
\begin{itemize}
\item non-recursive exit: given the \code{RunClosedW} clauses it exercises, an induction hypothesis for
the body, and a configuration-preserving reader transform, $P$ holds at the exit;
\item block exit: the same across the loop's two reader updates (fresh fixvar identifiers, then each
sibling's own \code{levelParams}), with an invariant accumulating each sibling's closedness, applied
form and closure equation.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{lem:rec_block_closed, lem:Erasure-run_bind_ok, lem:Erasure-run_list_mapM_ok, thm:Erasure-run_mkDef_ok, lem:Erasure-run_pure}
\lead{Idea} Both are the run algebra's exit lemmas with the sub-run's reader pinned to the caller's
configuration by \code{rfl}. The block exit's loop invariant is exactly the input
Lemma~\ref{lem:rec_block_closed} needs and \code{RunClosedW}'s \code{rc} clause consumes.
\end{proof}
\begin{lemma}[The two numeral dispatches, enumerated]
\label{lem:visitCases_match_tri}
\lean{LeanToLambdaBox.visitCases_match_tri, LeanToLambdaBox.visitConstructor_match_quad}
\leanok
\uses{def:Erasure-visitExpr, def:ConfigPinned}
\lead{In short} The two case dispatches inside the eraser are decided enumerations.
\begin{itemize}
\item \code{visitCases}' dispatch on (type name, \code{nat} mode) is a trichotomy: machine-\code{Nat},
machine-\code{Int} (both force \code{nat} to \code{.machine}), and a generic arm;
\item \code{visitConstructor}'s dispatch on (\code{nat} mode, constructor name) is a four-way case:
machine-\code{Nat.zero}, machine-\code{Nat.succ}, and two generic arms.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\lead{Idea} Split on the elaborator-generated matcher and close each arm by \code{rfl}; stated against
the generated matcher because a two-discriminant \code{Name}-literal match cannot be inverted at a
hypothesis whose subject is the match already applied to the monad's five arguments.
\end{proof}
\begin{remark}
\lead{Caveat} Editing either shipping match renumbers the matcher indices and breaks the proof, as a
build error.
\end{remark}
\begin{theorem}[The world-indexed induction, all eighteen motives]
\label{thm:visitExpr_shapeW}
\lean{LeanToLambdaBox.visitExpr_shapeW}
\leanok
\uses{def:RunClosedW, def:ShapeCW, def:Erasure-visitExpr, def:Erasure-visitMutual}
\lead{In short} \hl{One induction covers all eighteen} mutually recursive members of the erasure family.
\begin{itemize}
\item \lead{Given} \code{Cfg} on configurations and $P$ of the state and world, closed under the
eraser's steps (Definition~\ref{def:RunClosedW});
\item \lead{Then} at every \code{Cfg}-reader, every run of a member carries $P$ from entry to exit;
every member returning a term returns one fix-free, closed and applied.
\end{itemize}
The eighteen members:
\begin{center}
\begin{tabular}{p{0.54\linewidth}p{0.38\linewidth}}
\toprule
Member(s) & Deviation \\
\midrule
\code{visitExpr}, \code{visitLiteral}, \code{visitConstructor}, \code{visitConst}, \code{visitAppArgs}$^*$,
\code{visitLet}, \code{visitLambda}, \code{visitProj}, \code{visitApp}, \code{visitConstApp},
\code{visitCtorEta}, \code{visitCtorEtaGo}, \code{visitCasesEta}, \code{visitCasesEtaGo},
\code{visitCases}, \code{visitAlt}$^\dagger$ & none but as marked \\

$^*$: motive also takes the accumulator seed's three conjuncts as hypotheses & \\

\bottomrule
\end{tabular}
\end{center}
\lead{Status} \stProved{}; pure run algebra --- no lean4lean, no \code{sorryAx}.
\end{theorem}
\begin{proof}
\leanok
\uses{lem:visitCases_match_tri, lem:run_withLocalDecl_okW, lem:run_nonrec_exit_okW, lem:rec_block_closed, lem:Erasure-run_panic, lem:Erasure-run_bind_ok, def:NoFix, def:LBClosed}
\lead{Idea} One application of the family's mutual fixpoint induction, admissibility discharged by its
own lemmas, then eighteen step cases: unfold, step every bind, feed each primitive to
\code{RunClosedW}, open binders via the world-indexed binder lemmas, and discharge every \code{panic!}
arm (it returns the default term, fix-free, closed and applied). The two registering exits close via
Lemma~\ref{lem:run_nonrec_exit_okW}, the two numeral dispatches via Lemma~\ref{lem:visitCases_match_tri}.
\end{proof}
\begin{theorem}[The state-only induction, and its non-vacuity]
\label{thm:visitExpr_shape}
\lean{LeanToLambdaBox.visitExpr_shape, LeanToLambdaBox.runClosed_true}

\item \lead{Given} $\code{RunClosed}\ Q$;
\item \lead{Then} every successful run of a family member preserves $Q$, and every member returning a

\item \lead{Non-vacuity} the trivial predicate is \code{RunClosed}, so the hypothesis is satisfiable.

$\lambda s\,\_.\ Q\ s$ (Lemma~\ref{lem:runClosedW_of_runClosed}), with a trivial proof for each
configuration premise. Non-vacuity: at the trivial predicate every field's conclusion is \code{True}.
\end{proof}

\section{Constructor saturation, on the run}
\label{sec:coldstart:ctorsat}

This section shows the applied-versus-block constructor convention is established directly by the
eraser's run, not by a separate transformation.

\begin{lemma}[One argument out per argument in]
\label{lem:run_visitAppArgs_mkApps}

\end{lemma}
\begin{proof}
\leanok

\end{proof}
\begin{definition}[The saturation statement and its mask hypothesis]
\label{def:CtorSatConcl}
\lean{LeanToLambdaBox.CtorSatConcl, LeanToLambdaBox.MaskKeeps}
\leanok
\uses{def:Erasure-register_inductive, def:Erasure-EraseM, def:LBTerm-mkApps, def:LBTerm}
\lead{In short} What it means for an emitted constructor occurrence to keep all its arguments.
\begin{itemize}
\item $\code{CtorSatConcl}\ \code{ctx}\ \code{cctx}\ \code{ref}\ c\ s\ n\ t$: $t$ is the panic value, or
the constructor node reported for $c$, applied form with no block arguments, at exactly $n$ arguments
--- whenever the source occurrence carried at least $c$'s parameters plus fields;
\item $\code{MaskKeeps}\ s\ \code{ctx}\ c$: the hypothesis this is proved under --- every run of the
eraser's three queries at $c$ (its info, its type's info, \code{register\_inductive}) reports a mask
that keeps every field.
\end{itemize}
\end{definition}
\begin{remark}
\lead{Caveat} Nothing in the repository proves an instance of \code{MaskKeeps}; it is, by its own doc
comment, stronger than a consumer would need.
\end{remark}
\begin{theorem}[A saturated constructor occurrence is emitted saturated]
\label{thm:visitExpr_ctorSat}
\lean{LeanToLambdaBox.visitExpr_ctorSat, LeanToLambdaBox.visitApp_ctorSat, LeanToLambdaBox.visitConstructor_ctorSat}
\leanok
\uses{def:CtorSatConcl, def:ConfigPinned, def:Erasure-visitExpr}
\lead{In short} A fully-applied constructor occurrence is emitted fully applied.
\begin{itemize}
\item \lead{Given} the configuration pins $\code{nat} = \code{.peano}$, $\code{extern} =
\code{.preferLogical}$, and the mask hypothesis holds at $c$;
\item the source head is constant $c$, answered as a constructor of arity \code{arity} and not a
\code{casesOn}, occurring at \code{arity} arguments or more;
\item \lead{Then} \code{visitExpr} on it satisfies \code{CtorSatConcl} at the occurrence's own count:
the constructor node at exactly that many arguments, or the panic value.
\end{itemize}
\lead{Status} \stProved{}.
\end{theorem}
\begin{proof}
\leanok
\uses{def:CtorSatConcl, lem:run_visitAppArgs_mkApps, def:Erasure-register_inductive, def:Erasure-isErasable, lem:Erasure-run_panic}
\lead{Idea} Three layers. \code{visitConstructor} emits three slices (parameters, mask-selected fields,
over-application tail); under a total mask two arithmetic lemmas recompose the full count. A
constant-headed, non-\code{casesOn} application at that arity or more reaches \code{visitConstructor} at
its own array. \code{visitExpr} dispatches to \code{visitApp}, with an erasable occurrence ($\Box$) and
every \code{panic!} exit absorbed by the default disjunct.
\end{proof}
\begin{remark}
\lead{Deviation} Established on the run; MetaCoq ships a verified block/applied transformation instead
([S], Sec. 7.4).
\lead{Caveat} A fixture confirms the saturated case is reachable, but this whole layer has no consumer
until Section~\ref{sec:coldstart:bridge}'s open item closes.
\end{remark}

\begin{definition}[The inlining slack]

\leanok

\lead{In short} $\code{InlineExt}\ s\ s'$: $s'$ differs from $s$ at most in the \code{inlinings} field ---
the constant registry, the inductive registry and \code{gdecls} all agree.

\item implies both \code{Erasure.StateLe} and \code{Erasure.RunConcl}.
\end{itemize}

\begin{lemma}[The state effect of one mutual-block visit]
\label{lem:run_visitMutual_decomp}
\lean{LeanToLambdaBox.run_visitMutual_decomp, LeanToLambdaBox.run_inline_tail_decomp, LeanToLambdaBox.run_inline_prefix_decomp, LeanToLambdaBox.run_nonrec_exit_decomp, LeanToLambdaBox.run_rec_exit_decomp, LeanToLambdaBox.run_rec_exit_siblings, LeanToLambdaBox.run_rec_exit_siblings_closed}

\lead{In short} A successful \code{visitMutual n} run is a declaration-info query then one of three

\begin{itemize}
\item the axiom exit;
\item the non-recursive exit: inner \code{prepare\_erasure} and \code{visitExpr} runs on the
declaration's value, at a reader with no fixvar map and the declaration's own level parameters;
\item the recursive block exit: per-sibling runs with naming and closure equations, each open body

\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:InlineExt, thm:visitExpr_shape_all, thm:Erasure-run_addAxiom_ok, lem:Erasure-run_liftCoreM_ok, lem:Erasure-run_list_mapM_ok, thm:Erasure-run_mkDef_ok}
\lead{Idea} Unfold \code{visitMutual} and step its binds; the inlining prefix/tail peel into
\code{InlineExt} slack, and each exit decomposes separately, the block loop walked with an invariant
keeping the per-sibling runs. Closedness is Theorem~\ref{thm:visitExpr_shape_all}, hypothesis-free.
\end{proof}
\begin{remark}
\lead{Caveat} Does not decide which exit was taken (runtime data). Roughly half of
\code{ColdStartRun.lean}, this layer has no consumer: the live path goes through Chapter
\ref{chap:refinement} instead.
\end{remark}

\section{The cold-start registry invariant}
\label{sec:coldstart:reginv}

This section builds the invariant that relates a fixed specification environment to the mutable eraser
state, and a preservation kit that tiles the registration path step by step.

\begin{definition}[An inductive block, emitted unchanged]
\label{def:IndEmitted}
\lean{LeanToLambdaBox.IndEmitted}
\leanok
\uses{def:IndInfo, def:LBTerm-envLookup, def:GlobalDeclarations}
\lead{In short} For a source type former $n$,
$\code{IndEmitted}\ \code{env}\ \Gamma_{\mathrm{spec}}\ \Gamma\ n$ says the mutual-inductive block
$\Gamma_{\mathrm{spec}}$ declares at $n$'s block kername is declared, unchanged, in $\Gamma$.
\end{definition}
\begin{lemma}[Erasure at the empty context has no free variable]
\label{lem:Erases-noFVar}
\lean{LeanToLambdaBox.Erases.noFVar, LeanToLambdaBox.Erases.noFVar_of_noFVars, LeanToLambdaBox.VLCtx.find?_inr_cons_none}
\leanok
\uses{def:Erases, def:hasFVar, def:lean4lean-grounding}
\lead{In short} An erasure image taken at the empty local context is free-variable free.
\begin{itemize}
\item \lead{Given} $e$ erases to $t$ at a model local context binding no free variable;
\item \lead{Then} $t$ contains no free-variable node at all.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:Erases}
\lead{Idea} Induction on the erasure derivation. The variable arm is the relation's only producer of a
free-variable node, and its lookup premise contradicts the hypothesis; the two binder arms extend the
context with an anonymous entry, which answers no free-variable lookup; every other arm, box included, is
structural.
\end{proof}
\begin{definition}[The cold-start registry invariant]
\label{def:RegInvShape-prime}
\lean{LeanToLambdaBox.RegInvShape'}
\leanok
\uses{def:IndEmitted, def:SpecContent, def:IndCovered, def:ElimDecl, def:Lower, def:LowerFix, def:Erasure-EraseM, def:Kername, def:LBTerm-envLookup}
\lead{In short} $\code{RegInvShape'}\ \code{env}\ \code{bo}\ \Gamma_{\mathrm{spec}}\ s$ relates a
\hl{fixed} specification environment $\Gamma_{\mathrm{spec}}$ --- MetaCoq's pre-lowering source image
--- to the mutable state $s$. Twelve fields in three groups.
\begin{center}
\begin{tabular}{lll}
\toprule
Group & Field & Meaning \\
\midrule
$\Gamma_{\mathrm{spec}}$ alone & \code{spec} & meets \code{SpecContent} \\
 & \code{specClosed} & bodies are de~Bruijn closed \\
 & \code{specFVarFree} & bodies mention no free variable \\
\midrule
coverage & \code{consts} & registered constants are declared, at canonical kername \\
 & \code{inds} & registered inductives are covered \\
\midrule
emitted $\Gamma$ & \code{keys} & emitted keys are distinct \\
 & \code{defs} & a shared body is \Lower{}'s image, or a lowered block's $j$-th member \\
 & \code{defsTotal} & every non-runtime-key spec body is emitted with some body \\
 & \code{axioms} & a body-less spec constant is emitted body-less or pruned \\
 & \code{indsEmitted} & every registered block is emitted unchanged \\
 & \code{sub} & pruning only removes keys \\
 & \code{closed} & all emitted bodies are closed \\
\bottomrule
\end{tabular}
\end{center}
\end{definition}
\begin{remark}
\lead{Deviation} $\Gamma_{\mathrm{spec}}$ is fixed, not grown: \Lower{} is not monotone (a block can
turn a key into a runtime key).
\lead{Caveat} \code{defsTotal}, \code{indsEmitted} are registry-scoped, vacuous at the empty state,
unscoped only by Theorem~\ref{thm:RegInvShape-prime-lowerEnv}. \code{specEnv}, \code{lowerEnv},
\code{defns}, \code{erasesEnv} are Section~\ref{sec:coldstart:specenv} theorems, not fields here.
\end{remark}
\begin{lemma}[The invariant at the initial state]
\label{lem:RegInvShape-prime-empty}
\lean{LeanToLambdaBox.RegInvShape'.empty}
\leanok
\uses{def:RegInvShape-prime}
\lead{In short} At the default \code{ErasureState}, the invariant reduces to its three
$\Gamma_{\mathrm{spec}}$-only clauses.
\begin{itemize}
\item \lead{Given} \code{SpecContent}, closedness, and free-variable freedom of $\Gamma_{\mathrm{spec}}$;
\item \lead{Then} the invariant holds at the empty state.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:RegInvShape-prime}
\lead{Idea} Nine of the twelve clauses are vacuous or trivial at the empty state (unsatisfiable
antecedents, distinctness of the empty list, no emitted entry to speak about, or the ``pruned''
disjunct); the remaining three are the hypotheses.
\end{proof}
\begin{lemma}[Registering a body-less constant]
\label{lem:RegInvShape-prime-addAxiom}
\lean{LeanToLambdaBox.RegInvShape'.addAxiom, LeanToLambdaBox.RegInvShape'.addAxiom_run}
\leanok
\uses{def:RegInvShape-prime, def:Erasure-register_inductive, def:Erasure-addAxiomState}
\lead{In short} Registering a body-less constant preserves the invariant.
\begin{itemize}
\item \lead{Given} $\Gamma_{\mathrm{spec}}$ declares $n$ body-less too, and $n$'s kername is not already
an emitted key;
\item \lead{Then} the invariant survives; the same holds of a real run of \code{Erasure.addAxiom}, with
no further hypothesis.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:RegInvShape-prime, thm:Erasure-run_addAxiom_ok}
\lead{Idea} The state delta conses a body-less entry and inserts $n$ into the constant registry; the
lookup-across-a-cons lemmas and a case split on ``the inserted name or one already known'' discharge
\code{consts} and \code{defsTotal}. The run form composes the delta with the run algebra's
\code{addAxiom} lemma.
\end{proof}
\begin{lemma}[The non-recursive exit preserves the invariant]
\label{lem:RegInvShape-prime-constCons}
\lean{LeanToLambdaBox.RegInvShape'.constCons}
\leanok
\uses{def:RegInvShape-prime, def:Erasure-nonrecConstState, def:Lower, def:LowerFix, def:ElimDecl, def:LBClosed}
\lead{In short} Storing one constant with an emitted body preserves the invariant.
\begin{itemize}
\item \lead{Given} $\Gamma_{\mathrm{spec}}$ declares $n$ with some body $b_0$;
\item $t$ is either the \Lower{} image of $b_0$, or the $j$-th projection of a lowered fixpoint block
whose $j$-th key is $n$;
\item $t$ is de~Bruijn closed at level $0$, and $n$'s kername is fresh among the emitted keys;
\item \lead{Then} storing $n$ with body $t$ preserves the invariant.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:RegInvShape-prime}
\lead{Idea} As for the axiom step, with the registry insertion split into the two cases: \code{defs} is
the lowering hypothesis at the new key and the invariant elsewhere, \code{closed} is the closedness
hypothesis, and freshness gives \code{keys}.
\end{proof}
\begin{remark}
\lead{Why} The workhorse step: Lemma~\ref{lem:RegInvShape-prime-recConst} iterates it per block member,
and on a real run its closedness premise comes from Theorem~\ref{thm:visitExpr_shape_all}.
\end{remark}
\begin{lemma}[The block exit preserves the invariant]
\label{lem:RegInvShape-prime-recConst}
\lean{LeanToLambdaBox.RegInvShape'.recConst, LeanToLambdaBox.regInvShape'_foldl_recConstStep}
\leanok
\uses{def:RegInvShape-prime, def:Erasure-nonrecConstState, def:LowerBlock}
\lead{In short} A whole mutual block is registered in one step, and the invariant survives.
\begin{itemize}
\item \lead{Given} the block's \code{LowerBlock} witness holds at $\Gamma_{\mathrm{spec}}$, the member
names sit at the block's own indices, every member key is fresh against the pre-existing emitted
environment, and the member keys are pairwise distinct;
\item \lead{Then} the invariant holds at the block-registering state; the member-by-member version
iterates the same step along the fold.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{lem:RegInvShape-prime-constCons, def:LowerBlock}
\lead{Idea} The block-registering state folds the non-recursive step over the member list; the
\code{defs} disjunct comes from the block's own \code{LowerBlock} witness, and freshness against
earlier members is exactly the distinctness hypothesis.
\end{proof}
\begin{remark}
\lead{Caveat} The distinctness premise is \code{EraserAsks.block\_keys\_distinct}, which is refuted in
general (finding F-UNSAFEREC: a mutual unsafe definition together with its unsafe-recursive twin); every
statement downstream is bounded by that.
\end{remark}
\begin{lemma}[A prefix of body-less entries]
\label{lem:RegInvShape-prime-axiomCons}
\lean{LeanToLambdaBox.RegInvShape'.axiomCons, LeanToLambdaBox.regInvShape'_axiomPrefix}
\leanok
\uses{def:RegInvShape-prime, def:LBTerm-envLookup}
\lead{In short} Consing one body-less \emph{entry} (the constant registry untouched) preserves the
invariant.
\begin{itemize}
\item \lead{Given} $\Gamma_{\mathrm{spec}}$ declares that key body-less, and the key is fresh;
\item \lead{Then} the invariant survives; by induction, so does a whole prefix of such entries with
distinct keys.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:RegInvShape-prime}
\lead{Idea} The cons case is the lookup-across-a-cons lemmas at a fresh key, with \code{consts},
\code{inds} and \code{defsTotal} unchanged since no name was registered; the prefix case inducts on the
prefix.
\end{proof}
\begin{lemma}[The emitted block entry]
\label{lem:RegInvShape-prime-blockCons}
\lean{LeanToLambdaBox.RegInvShape'.blockCons}
\leanok
\uses{def:RegInvShape-prime, def:OneInductiveBody, def:Erasure-addAxiomState}
\lead{In short} Consing the mutual-inductive block entry the registration state emits preserves the
invariant.
\begin{itemize}
\item \lead{Given} $\Gamma_{\mathrm{spec}}$ holds that same block at that key;
\item \lead{Then} the invariant survives.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:RegInvShape-prime, def:IndEmitted}
\lead{Idea} The lookup-across-a-cons lemmas at a fresh key; the premise is the unscoped inductive clause
read at one key, so \code{indsEmitted} is preserved and no body clause is touched.
\end{proof}
\begin{lemma}[Two transports at a larger state]
\label{lem:RegInvShape-prime-stateCongr}
\lean{LeanToLambdaBox.RegInvShape'.stateCongr, LeanToLambdaBox.RegInvShape'.indsGrow}
\leanok
\uses{def:RegInvShape-prime, def:IndEmitted, def:IndCovered}
\lead{In short} The invariant transports across registry growth that does not touch \code{gdecls}.
\begin{itemize}
\item constant-registry growth: given every new name is one the old state knew or one
$\Gamma_{\mathrm{spec}}$ declares body-less, the invariant transports;
\item inductive-registry growth: given every newly-known name is covered and has its block emitted, the
invariant transports.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:RegInvShape-prime}
\lead{Idea} Clauses not mentioning the moved registry rewrite across the equalities; \code{defsTotal}'s
new-name case is vacuous, since a body-less $\Gamma_{\mathrm{spec}}$ entry declares no body and
body-less is the only kind \code{addAxiom} adds.
\end{proof}
\begin{lemma}[The inductive path, at the run]
\label{lem:RegInvShape-prime-register_inductive_run}
\lean{LeanToLambdaBox.RegInvShape'.register_inductive_run}
\leanok
\uses{def:RegInvShape-prime, def:IndEmitted, def:Erasure-register_inductive, def:Erasure-ConstExt, def:IndCovered}
\lead{In short} A cold \code{register\_inductive} run preserves the invariant, given five conditions
read off its own final state $s_1$.
\begin{itemize}
\item \lead{Given} \code{register\_inductive} runs at a name the inductive registry lacks, ending at
$s_1$, where: emitted keys are distinct; every body-less final entry is body-less in
$\Gamma_{\mathrm{spec}}$; the emitted block at the call's kername equals $\Gamma_{\mathrm{spec}}$'s;
every newly registered constant was already known at $s$ or is body-less in $\Gamma_{\mathrm{spec}}$;
every newly registered inductive was already known at $s$ or is covered with its block emitted;
\item \lead{Then} the invariant holds at $s_1$.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{lem:RegInvShape-prime-axiomCons, lem:RegInvShape-prime-stateCongr, lem:RegInvShape-prime-blockCons, thm:Erasure-run_register_inductive_cold_ok}
\lead{Idea} The cold branch's intermediate states (the \code{@[extern]} axiom prefix, then the block
cons) are rebuilt from the run algebra's constant-extension report, then chained: axiom prefix, state
transport, block cons, registry growth.
\end{proof}
\begin{remark}
\lead{Caveat} Assumes part of its own conclusion: key-distinctness at $s_1$ is the invariant's own
\code{keys} field, read off the final state. A transport at a known-good state, not free-standing
preservation.
\end{remark}
\begin{lemma}[A parameter-free body is its own instantiation]
\label{lem:instantiateLevelParams_eq_self}
\lean{LeanToLambdaBox.instantiateLevelParams_eq_self}
\leanok
\lead{In short} A source term with no level parameter is unchanged by level instantiation, at any
substitution.
\end{lemma}
\begin{proof}
\leanok
\uses{asm:lean-reflection-axioms}
\lead{Idea} Unfold the instantiation and apply the corresponding core lemma, whose guard is exactly the
absence of a level parameter.
\end{proof}
\begin{theorem}[Level-scope transport at a parameter-free body]
\label{thm:erases_any_scope_of_paramFree}
\lean{LeanToLambdaBox.erases_any_scope_of_paramFree}
\leanok
\uses{def:Erases, def:NoMaxLevels, def:lean4lean-grounding}
\lead{In short} \lbox{} carries no universe levels, so \hl{an erasure derivation at one scope is a
derivation at every scope} once the body has no level parameter left to instantiate.
\begin{itemize}
\item \lead{Given} $b$ has no level parameter and satisfies \code{NoMaxLevels};
\item $b$ erases to $b_0$ at the empty local context in scope \code{Us};
\item \lead{Then} $b$ erases to $b_0$ at the empty local context in every scope.
\end{itemize}
\lead{Status} \stProved{}.
\end{theorem}
\begin{proof}
\leanok
\uses{lem:instantiateLevelParams_eq_self, thm:Erases-instL, asm:lean-reflection-axioms}
\lead{Idea} Instantiate \code{Us} at level zero (well-formed in any scope) and move the derivation via
the erasure relation's level-instantiation theorem (\code{NoMaxLevels}). The instantiation is the
identity on a parameter-free body (Lemma~\ref{lem:instantiateLevelParams_eq_self}) and the empty
context, so the moved derivation is the original one at the new scope.
\end{proof}
\begin{remark}
\lead{Deviation} Available only at level-parameter-free bodies; MetaCoq's environment erasure
quantifies over every instantiation, since Rocq's constants are universe-polymorphic ([S], Sec. 7.3).
Chapter~\ref{chap:source}'s \code{defns\_needs\_paramFree} refutes the unguarded clause.
\end{remark}

\section{From the invariant to the environment relation}
\label{sec:coldstart:specenv}

These four theorems live in \code{SpecEnv.lean}, shared with Chapter~\ref{chap:source}; they matter here
because Theorem~\ref{thm:bridgeEnv_of_regInv} consumes them.

\begin{lemma}[The invariant, read as a specification environment]
\label{lem:RegInvShape-prime-specEnv}
\lean{LeanToLambdaBox.RegInvShape'.specEnv}
\leanok
\uses{def:RegInvShape-prime, def:SpecEnv}
\lead{In short} The registration invariant is in particular a specification environment: \code{SpecEnv}'s
four fields are exactly the invariant's specification-side ones.
\end{lemma}
\begin{proof}
\leanok
\uses{def:RegInvShape-prime}
\lead{Idea} Field by field: the content clause, the two coverage clauses, and free-variable freedom.
\end{proof}
\begin{theorem}[The emitted environment is the lowered image]
\label{thm:RegInvShape-prime-lowerEnv}
\lean{LeanToLambdaBox.RegInvShape'.lowerEnv}
\leanok
\uses{def:RegInvShape-prime, def:LowerEnv, def:RegSaturated}
\lead{In short} A saturated run's invariant gives \hl{\LowerEnv{}} on the emitted environment.
\begin{itemize}
\item \lead{Given} the invariant holds at $s$, and the run is saturated: every declared non-runtime-key
definition of $\Gamma_{\mathrm{spec}}$ is some registered constant's, and every declared block some
registered inductive's;
\item \lead{Then} $\LowerEnv{}\ \Gamma_{\mathrm{spec}}\ s.\code{gdecls}$.
\end{itemize}
\lead{Status} \stProved{}.
\end{theorem}
\begin{proof}
\leanok
\uses{def:RegInvShape-prime, def:RegSaturated}
\lead{Idea} All eight clauses of \code{LowerEnv} come from the correspondingly named clauses of the
invariant; the two scoped clauses are unscoped by the two saturation premises.
\end{proof}
\begin{theorem}[The delta column, from the run's own records]
\label{thm:RegInvShape-prime-defns}
\lean{LeanToLambdaBox.RegInvShape'.defns}
\leanok
\uses{def:RegInvShape-prime, def:Erases, def:ReachableFrom, def:NoMaxLevels}
\lead{In short} Every tabled, reached constant's compiler body erases to $\Gamma_{\mathrm{spec}}$'s
declared body \hl{at every level scope}.
\begin{itemize}
\item \lead{Given} the invariant; every kername reachable from $t$ is declared in
$\Gamma_{\mathrm{spec}}$; every tabled compiler body is level-parameter free with no maximum-level
expression;
\item \lead{Then} for every tabled $c$ that $t$ reaches, $\Gamma_{\mathrm{spec}}$ declares $c$ with a
body $b_0$, and the compiler body erases to $b_0$ at every scope and instantiation.
\end{itemize}
\lead{Status} \stProved{}; measured at nine names (the three standard plus six level-instantiation
reflection names), no \code{sorryAx}.
\end{theorem}
\begin{proof}
\leanok
\uses{def:RegInvShape-prime, lem:instantiateLevelParams_eq_self, thm:erases_any_scope_of_paramFree, def:SpecContent, asm:lean-reflection-axioms}
\lead{Idea} Reachability puts the key in the environment; \code{SpecContent}'s delta clause reads its
entry at the run's scope; the level-parameter premise makes the unguarded quantification reachable via
Lemma~\ref{lem:instantiateLevelParams_eq_self} and Theorem~\ref{thm:erases_any_scope_of_paramFree}.
\end{proof}
\begin{theorem}[The environment relation of a run]
\label{thm:RegInvShape-prime-erasesEnv}
\lean{LeanToLambdaBox.RegInvShape'.erasesEnv}
\leanok
\uses{def:RegInvShape-prime, def:ErasesEnv, def:ConstOrigin, def:ReachableFrom}
\lead{In short} \hl{\ErasesEnv{}} holds along everything the erased program reaches.
\begin{itemize}
\item \lead{Given} the invariant, the reachability premise, level-parameter freedom of the tabled
bodies, and that every tabled constant is a plain constant of the model;
\item \lead{Then} $\ErasesEnv{}\ \code{env}\ \code{bo}\ \Gamma_{\mathrm{spec}}\ t$.
\end{itemize}
\lead{Status} \stProved{}.
\end{theorem}
\begin{proof}
\leanok
\uses{lem:RegInvShape-prime-specEnv, thm:RegInvShape-prime-defns, lem:SpecEnv-erasesEnv, asm:lean-reflection-axioms}
\lead{Idea} Chapter~\ref{chap:source}'s \code{SpecEnv.erasesEnv} takes three premises the state does not
record: reachability (the hypothesis), the strengthened delta column
(Theorem~\ref{thm:RegInvShape-prime-defns}), and the table clause (discharged at the bridge from the
reified table).
\end{proof}

\begin{definition}[The block's fixvar map]
\label{def:fixvarMap}
\lean{LeanToLambdaBox.fixvarMap, LeanToLambdaBox.fixvarMap_get?_some, LeanToLambdaBox.fixvarMap_ids_subset, LeanToLambdaBox.BridgeInv.fixvars_ids_subset}
\leanok
\uses{def:Erasure-visitMutual, def:Erasure-prepare_erasure}
\lead{In short} $\code{fixvarMap}\ \code{nms}\ \code{ids}$: the map \code{visitMutual} installs while
erasing a mutual block, each stripped source name to the fresh identifier minted for it.
\begin{itemize}
\item a hit in the map is a hit at one common index of the two lists;
\item two equal-length, duplicate-free name lists assembling the same map share identifiers.
\end{itemize}
\end{definition}
\begin{remark}
\lead{Why} Supplies the form the binder steps consume: at any \code{BlockKeyed} pair, each identifier is
reserved by the ambient generator and is not a model-context variable.
\end{remark}
\begin{definition}[A faithful description of the fixvar map]
\label{def:BlockKeyed}
\lean{LeanToLambdaBox.BlockKeyed}
\leanok
\uses{def:fixvarMap, def:Witness-SourceTable, def:Kername, def:Erasure-EraseM}
\lead{In short} $\code{BlockKeyed}\ \code{tbl}\ \code{ctx}\ \code{nms}\ \code{ids}$ pins the fixvar map
to one well-behaved instance.
\begin{itemize}
\item the reader's fixvar map \emph{is} $\code{fixvarMap}\ \code{nms}\ \code{ids}$, of equal length;
\item \code{nms} is duplicate-free;
\item the kername map is injective on the tabled names: if a tabled name's kername is a block kername,
the name itself is a block name.
\end{itemize}
\end{definition}
\begin{remark}
\lead{Caveat} Injectivity is restricted to tabled names because unrestricted it is false (finding
F-KERNAME); duplicate-freedom's shipping counterpart is the refuted
\code{EraserAsks.block\_keys\_distinct}.
\end{remark}

\item \lead{Given} the primitive specifications, a pinned configuration, and that the block the call is

\item \lead{Then} the run leaves the inductive registry modelled.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok

\end{proof}

\begin{definition}[The bridge invariant]
\label{def:BridgeInv}
\lean{LeanToLambdaBox.BridgeInv}

\toprule
Field & Meaning \\
\midrule

\begin{lemma}[Three consequences of the modelled context]

\item $\Delta$ is a well-formed model context at the ambient level scope;
\item $\Delta$ has no de~Bruijn entry.
\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:BridgeInv, asm:lean-reflection-axioms}
\lead{Idea} All three are read off the mixed-context witness: a well-formed mixed context whose two

\end{proof}
\begin{lemma}[The two frame rules]
\label{lem:BridgeInv-mono}
\lean{LeanToLambdaBox.BridgeInv.mono, LeanToLambdaBox.BridgeInv.mono_state}
\leanok
\uses{def:BridgeInv, def:IndRegistryModelled, def:Erasure-RunConcl}
\lead{In short} The invariant is monotone in the generator and survives state growth.
\begin{itemize}
\item generator: the invariant survives advancing the name generator;
\item state: given a canonical run conclusion $s \to s'$ and that $s'$'s registry is still modelled,

\end{itemize}
\end{lemma}
\begin{proof}
\leanok
\uses{def:BridgeInv, def:Erasure-RunConcl}

\end{proof}

\end{itemize}
\end{lemma}
\begin{proof}
\leanok

\label{lem:BridgeInv-mkLocalDecl}
\lean{LeanToLambdaBox.BridgeInv.mkLocalDecl, LeanToLambdaBox.BridgeInv.mkLetDecl}

\begin{theorem}[The erasure half of the capstone, discharged]
\label{thm:erasure_bridge_of_run}
\lean{LeanToLambdaBox.erasure_bridge_of_run}
\leanok
\uses{def:ErasureSpec, def:EraserAsks, def:UpstreamAsks, def:Witness-SourceTableAdequate, def:TableSafe, def:TableBlocks, def:ConfigPinned, def:CompilerBodies, def:Supported, def:lean4lean-grounding, def:Erases, def:Lower, def:SpecEnv, def:Erasure-visitExpr, def:Erasure-prepare_erasure}
\lead{In short} A run's prepared-and-walked output \hl{factors through \Erases{} then \Lower{}} at every
specification environment the final state admits.
\begin{itemize}
\item \lead{Given} \code{ErasureSpec}, \code{EraserAsks}, \code{UpstreamAsks};
\item the three table hypotheses (\code{SourceTableAdequate}, \code{TableSafe}, \code{TableBlocks}), a
pinned configuration, and \code{CompilerBodies};
\item \code{pe} is \code{Supported} and translates into the model; \code{prepare\_erasure} took $e$ to
\code{pe} from the empty state, and \code{visitExpr} then took \code{pe} to $t$;
\item \lead{Then} at every $\Gamma_{\mathrm{spec}}$ the final state admits, there is $t_0$ with
$\Erases{}\ \code{env}\ []\ []\ \code{pe}\ t_0$ and $\Lower{}\ \Gamma_{\mathrm{spec}}\ t_0\ t$.
\end{itemize}
\lead{Status} \stProved{}; \stInherited{} through lean4lean; conditional on \stAssumed{}
\code{ErasureSpec}, \code{EraserAsks}, \code{UpstreamAsks}.
\end{theorem}
\begin{proof}
\leanok
\uses{lem:run_prepare_erasure_state, def:BridgeInv, def:IndRegistryModelled, thm:visitExpr_refines_erasesLB, thm:step_visitExpr, lem:step_visitLiteral, lem:step_visitConstructor, lem:step_visitConst, lem:step5, lem:step_visitAppArgs, lem:step_visitProj, lem:step_visitConstApp, lem:step_visitCtorEta, lem:step_visitCases, lem:step_visitAlt, asm:lean4lean-trust, asm:lean-reflection-axioms}
\lead{Idea} Lemma~\ref{lem:run_prepare_erasure_state} puts the post-preparation state at the empty one,
where the bridge invariant holds by construction (empty reader and context trivialise every field).
\lead{Steps} Apply Chapter~\ref{chap:refinement}'s refinement theorem with all eighteen member steps as
proved terms; its first motive read in the ambient mode unfolds to the conclusion's existential.
\end{proof}
\begin{remark}
\lead{Caveat} \code{TableBlocks} is unused in the proof term and has no consumer anywhere. The
footprint carries \code{sorryAx} plus the reflection axioms, routing the relevance decision through
lean4lean's checker; the capstone's own footprint is 33 names including \code{sorryAx}.
\end{remark}
\begin{definition}[The residual, as one named binder]
\label{def:ErasureBridge}
\lean{LeanToLambdaBox.ErasureBridge}
\leanok
\uses{def:ErasesEnv, def:LowerEnv, asm:ErasureBridge-erasesEnv, asm:ErasureBridge-lowerEnv}
\lead{In short} $\code{ErasureBridge}\ \code{env}\ \code{bo}\ \Gamma_{\mathrm{spec}}\ \Gamma\ t_0$ bundles
exactly two environment results.
\begin{itemize}
\item \code{erasesEnv}: $\Gamma_{\mathrm{spec}}$ erases the source environment along everything $t_0$
reaches;
\item \code{lowerEnv}: $\Gamma$ is the lowered, pruned image of $\Gamma_{\mathrm{spec}}$.
\end{itemize}
\end{definition}
\begin{remark}
\lead{Caveat} Both fields are Assumptions of Chapter~\ref{chap:trust}, unfulfilled at every green rung
(the open item below).
\lead{Why} \code{ErasesEnv} counterparts MetaCoq's environment erasure ([S], Sec. 7.3); \LowerEnv{} is
the extra Lean-specific layer for \Lower{}'s own steps.
\end{remark}
\begin{theorem}[The bridge's two environment fields, derived]
\label{thm:bridgeEnv_of_regInv}
\lean{LeanToLambdaBox.bridgeEnv_of_regInv}
\leanok
\uses{def:RegInvShape-prime, def:ErasureBridge, def:RegSaturated, def:SpecEnv, def:LBWfSpec, def:ErasesEnv, def:LowerEnv, def:ReachableFrom, def:ConstOrigin}
\lead{In short} \hl{At a saturated state the invariant assembles everything the composition needs at
once}.
\begin{itemize}
\item \lead{Given} the invariant holds at \code{sf} against $\Gamma_{\mathrm{spec}}$, the run is
saturated for it, and every kername $t_0$ reaches is declared in $\Gamma_{\mathrm{spec}}$;
\item every tabled body is level-parameter free with no maximum-level expression, and every tabled
constant is a plain constant of the model;
\item \lead{Then} at once: the specification environment for \code{sf}, well-formedness
$\code{LBWfSpec}\ \Gamma_{\mathrm{spec}}$, and both \code{ErasureBridge} fields.
\end{itemize}
\lead{Status} \stProved{}; one line of Lean, measured at nine names in \code{test/ledger.expected},
no \code{sorryAx}.
\end{theorem}
\begin{proof}
\leanok
\uses{lem:RegInvShape-prime-specEnv, thm:RegInvShape-prime-erasesEnv, thm:RegInvShape-prime-lowerEnv, def:RegInvShape-prime, asm:lean-reflection-axioms}
\lead{Idea} Four projections: the specification environment (Lemma~\ref{lem:RegInvShape-prime-specEnv});
\code{LBWfSpec} as the invariant's key-distinctness and specification-closedness clauses; the
environment relation (Theorem~\ref{thm:RegInvShape-prime-erasesEnv}); the lowered image
(Theorem~\ref{thm:RegInvShape-prime-lowerEnv}) at saturation.
\end{proof}

\subsection*{The open item}

\stOpen{} \lead{Open} Nothing in the repository produces a \code{RegInvShape'} for a state the
shipping eraser actually reaches.
\begin{itemize}
\item Every theorem about a \emph{run} is proved; every theorem about the \emph{invariant} is proved;
nothing joins them.
\item The only inhabitants: Lemma~\ref{lem:RegInvShape-prime-empty} (the empty state) and a hand-built
one-definition fixture in \code{SpecEnv.lean}.
\item Consequence: the capstone's \code{shipping\_erase\_correct\_firstorder} carries hypothesis
\code{hbridge} (a $\Gamma_{\mathrm{spec}}$ with both \code{ErasureBridge} fields at the final state),
discharged at none of the eight green rungs. Theorem~\ref{thm:bridgeEnv_of_regInv} is its interface.
\item \code{doc/rework/08-REPAIRS-W5.md} sketches the fix: share the erasure witness between the
specification environment and the emitted body, at an environment that grows with the state.
\item Three obstructions: \code{BridgeInv}'s fixed level scope versus \code{visitMutual}'s own
\code{levelParams} per member; alpha-equivalence (a tabled body is pinned to the prepared source body
only up to it, while \Lower{} is not alpha-closed on its source); and ``every specification
environment'' versus ``one environment, produced''.
\item Section~\ref{sec:coldstart:reginv}'s preservation kit is what such a theorem would use; it has no
live proof path to the capstone yet.
\end{itemize}

\subsection*{Deviations from the paper and caveats}

\begin{itemize}
\item Applied-versus-block constructors are fixed on the run (Theorem~\ref{thm:visitExpr_ctorSat},
Theorem~\ref{thm:visitExpr_shape_all}); MetaCoq verifies a block/applied transformation instead ([S],
Sec. 7.4). The saturation layer has no consumer.
\item The delta column needs level-parameter-free bodies (Theorem~\ref{thm:erases_any_scope_of_paramFree});
MetaCoq quantifies over every instantiation. The general clause is refuted in Chapter~\ref{chap:source}.
\item \Lower{} has no MetaCoq counterpart, so \code{ErasureBridge} carries \code{LowerEnv} beside
\code{ErasesEnv}.
\item Two heartbeat budgets are set for reproducibility: four million for the induction, one million for
the block decomposition.
\item Roughly half of \code{ColdStartRun.lean} and the whole saturation layer are proved but unconsumed.
\item No \code{sorry}, \code{partial}, \code{unsafe}, \code{axiom} or reflection-based decision
procedure occurs in the three cold-start files; the only trust is the parameter bundles and the
\code{Lean.Expr} reflection axioms.
\end{itemize}
